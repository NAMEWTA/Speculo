# 安全与授权模型

## 范围与默认行为

默认脚本只读取本地元数据、指定的配置字段、可访问的应用和启动项，并在输出目录创建报告。它不会启动任何待检查工具，因此不存在为获得版本号而意外执行未知 shim、仓库 hook、卸载命令或 shell profile 的默认路径。不联网，不自动安装依赖，不请求管理员权限。

所谓全面，是“明确列出每个检查类别及其覆盖缺口”，不是无条件递归整盘。项目根需明确授权；其他用户、外接卷、网络文件系统、WSL 客体、容器和系统受保护区域不属于默认完整覆盖。检测到容器/SSH/WSL 信号时，必须说明报告的主机边界。

## 分类与禁止误判

| 类别 | 示例 | 默认处理 |
| --- | --- | --- |
| 可重建缓存候选 | npm `_cacache`、pip 缓存、Go build cache | 先证明路径/结构，再评估离线需求；少数情况可隔离 |
| 依赖仓库 | Maven local repository、pnpm store、Go mod cache、Cargo registry/git | 不能承诺全部可删；唯一产物、定制内容、离线构建需核实 |
| 工具/SDK 安装根 | JDK、Node 管理器、rustup、uv Python | 由管理器卸载版本；检查项目 pin、IDE、全局工具与架构 |
| 配置及状态 | `.m2/settings.xml`、Cargo Home、`.npmrc`、Docker contexts | 凭据与行为设置可能混在一起；禁止整体清空 |
| 项目产物 | `.venv`、`node_modules`、`target`、`build`、`dist` | 目录名只是线索；可能含 editable 项目、本地源码或唯一文件 |
| 个人与系统数据 | 文档、浏览器资料、密钥、数据库、驱动、共享运行库 | 保护；额外授权也必须有具体身份、影响与备份方案 |

修改时间不是最后使用时间；名称相同不是内容重复；已卸载应用的同名文件不一定归该应用所有；“未被某一个管理器列出”不意味着无主。文件夹很大、很旧、名字叫 cache，都不是删除授权。

## 风险与审批

R0 仅观察。R1 是可重建缓存的复核候选。R2 可能影响离线构建、应用、登录或复现。R3 涉及系统/驱动/共享组件/应用数据/备份等。P 保护。审批要绑定操作、精确对象、理由和数据选择，不接受“全部同意”“把大的都删了”作为生成通配删除命令的理由。

自动隔离计划使用 `Q-...` ID，24 小时有效。`approve` 仅接受真实计划中的不重复 ID；`apply` 需要同一计划字节的 SHA-256、同主机、确认 token 和工具关闭声明。修改计划后旧审批失效。代理不得替用户自行审批。

SHA-256 不是数字签名；同一账户内有权限修改计划和审批的人仍可以修改它们。元数据快照不读取内容，不能识别恶意保留大小和时间戳的内容篡改。本实现不是对抗恶意同权限进程或内核/文件系统攻击的安全产品。

## 自动隔离的硬边界

只允许默认位置、结构已识别的 npm `_cacache`、pip cache 和 Go build cache。默认路径不是用户环境变量任意指定的目录。全树扫描需完整，没有链接、联接、重解析点、云占位、跨设备子项、特殊文件或硬链接；全部已观察到的修改时间达到阈值。未知目录布局不自动放宽规则。

执行前和每次重命名前重新测量并比较根身份及摘要。只在同一文件系统内 `rename` 到 `~/.speculo-hygiene/quarantine/`，没有复制后删除、递归删除或永久清除功能。隔离不释放空间，可能使后续构建重新下载缓存。使用原生清理命令释放空间属于另一个独立确认阶段。

相关应用、IDE、daemon、安装器和构建必须关闭；脚本无法跨平台证明不存在使用该缓存的进程。`--tools-closed` 只是用户声明。重命名后的漂移会停止后续操作并记录，不在未知状态下自动覆盖回滚。

## 日志、失败与恢复

执行先写 receipt 再改路径；每步记录 pending/prepared/moved 等状态。遇错停止后续动作，之前已移动的内容保留。恢复会核对主机、固定目标路径和快照，不覆盖重新生成的原目录，也不做隐式合并。崩溃后可以依据 prepared 状态和源/目标是否存在进行保守恢复；真实断电与文件系统持久性仍依赖操作系统，模拟异常测试不是断电可靠性证明。

`operation.lock` 防止本工作并发操作，不是所有包管理器共享的锁。存在旧锁时先检查 receipt、PID 和实际进程，确认没有活动操作后人工处理；禁止无条件删锁重试。

永久删除、原生卸载、系统维护的回滚不属于隔离恢复保证。必须在这些操作前独立备份并说明不可逆边界。

## 路径、隐私与性能限制

不跟随已识别的符号链接/目录联接/重解析点；不读取标记为离线/云占位的文件，不主动水合。不能普遍识别所有 bind mount、macOS firmlink、同设备映射或远程挂载；不得据此宣称“绝不触达任何网络文件系统”。扫描预算是协作式截止；单个内核元数据调用阻塞时不能保证及时中断。

大小基于已读取的元数据。按设备和 inode 去重已测量硬链接/重叠路径，但 APFS/其他克隆、稀疏、压缩、远程文件标识和文件仍被进程持有都会影响真实释放量。

报告中的当前 home 替换为 `~` 并不完全匿名：项目名、软件名、其他账户路径等仍可能敏感。私密计划和 receipt 保存绝对路径。POSIX 新建文件使用 0600、专用目录使用 0700；Windows 继承父目录 ACL，不声称已建立专用 DACL。已有输出目录权限不会被擅自重写。
