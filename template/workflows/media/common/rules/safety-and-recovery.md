# Safety, budgets and recovery

external_actions=disabled。本期无发布、上传、登录、评论、自动回复、付费模型 API。额外下载、安装或费用须另行取得动作级授权，在本包外完成后恢复。权限失败与无能力不是让 Agent 绕过限制的理由。

缺关键输入一次列明并复用已有回答；非阻塞缺项可标假设继续研究，不无限追问。相同输入先查已验证产物；同一错误无进展连续两次停止。研究最多三轮；预览最多三轮修订，之后列问题与人工接管路径。

401/403 停止；429/5xx 仅只读或明确幂等请求最多安全重试两次，合计上下层尝试。未来外部写入超时结果为 unknown，先核验原任务，不能盲重发。本期根本没有对外发布接口，不虚构 published 状态。

路径拒绝父目录、绝对子路径、反斜杠、危险分隔和符号链接。写前重读，原子替换；已存在锁不删除。普通失败仅清理本次创建的临时目录；进程中断遗留的锁/暂存需核对原 owner 和工件后人工恢复，不自动接管。

输入或媒体字节改变使旧批准失效。审批 JSON 不是身份认证，宿主负责取得真实人工决定；Agent 不得自批。测试夹具必须显著标模拟，不能用于真实账号授权。

第三方脚本需逐文件审查、固定版本、查许可和外联。HAND_DRAWN_OFFLINE=1 是受信任上游的离线协议，不是任意恶意代码的网络沙箱。浏览器网络拦截也不使任意HTML安全。没有完整配方/缓存/模型能力时只阻塞相关分支，不编造成功。

指标缺失写 null 与 missing_reason，不写0；评论不是事实，相关性不是因果。素材/音乐/字体/肖像许可与 Skill 许可证分别核查。技术测试不能冒充实际视觉或人工审核。
