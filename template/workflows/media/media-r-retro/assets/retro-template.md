# 复盘与下一轮

## 数据范围
平台/账号、内容版本、发布年龄、统计窗口、来源、单位。缺失为null+missing_reason；人工回执未核验不能标真实上线。

连接原Change、brief版本/摘要、配方来源/版本与真实执行报告；分列实际指标、同口径比较基线、观察到的差异和因果推断。没有对照时写明无法归因，不把时间相关当效果；仍给出下一次能证伪的具体假设与观察。

## 问题与证据
事实纠错、理解盲点、人工改稿、失败工具、返工镜头、实际成本；无测量不估“节省百分比”。

## 单变量实验
唯一主要变量、对照、预期观察、统一窗口、混杂因素、停止条件。样本不足仅假设。

## 模板候选
实际同类样本数量、失败证据、五类模板之一、候选全文、适用边界、provenance、待人工确认。未满3–5条不固化。
