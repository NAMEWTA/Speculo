# 主题整合与知识综合

先确定要回答的主题问题和来源范围，读取相关讲义、材料、用户回答、作业与复习证据。完整来源不必全部搬进一棵目录，优先链接已有记录。

## 建立连贯理解

对齐术语和概念关系，合并重复表述，明确不同材料适用的版本、条件和视角。按主题组织有用结论，保留实际冲突、证据缺口和重要反例，不把所有来源压平成一致观点。

关键主张保留可回读来源：原文章/源码/讲义的位置，以及涉及学习表现时的实际作答或复习记录。类比和模型归纳不冒充一手证据；引用的摘要不能替代需要核实的原文。

组织成适合后续使用的解释、概念图、实例和应用边界。只有来源较多或主张复杂时使用来源表，不强制 claim ID、manifest、JSON 或版本 sidecar。

## 更新长期知识

优先更新已有主题笔记，说明当前结论和被替代观点的原因；重要历史理由可链接保留。原始材料、用户答案与既有评审不被综合覆盖。

项目已有知识位置直接使用；没有时可将有长期价值的主题放进 `knowledge/context/`，当前学习过程继续留在学习记录。具体按 [持久化](../../../references/memory.md) 处理。

用户明确需要整理目录时才移动资料，并检查目标冲突、完整性与引用；知识综合本身不要求物理嵌套或将归档原文恢复为活动状态。

## 交付

给出综合后的主线、关键来源、仍有争议或未知的内容以及适用边界。区别“材料已综合”和“学习者已掌握”，不能由整理完成推导保持能力。

尚有学习问题保留在原入口；需要结束整个主题时再 [归档](../learning-a-archive/SKILL.md)。
