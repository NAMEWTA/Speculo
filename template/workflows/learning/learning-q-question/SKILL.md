# 问答练习与主动探究

先识别两种不同意图：用户要“考我、让我先答、苏格拉底练习”时留出作答空间；用户要“替我找盲区、直接深挖”时主动研究与讲解。用户已指定方式就沿用，不把主动探究改成考试。

## 先答后讲

围绕一个真实学习目标选择问题，帮助暴露定义、因果机制、假设、反例或迁移判断。问题数量与节奏跟随用户要求和学习情况，不按固定批次输出。

不提前泄露正在练习的答案。用户缺先修知识时提供中性提示或必要基础，回答后保留原文，再指出正确之处、具体误解和推理缺口。反馈解释为什么以及怎样改，不只给分。

新的追问来自回答中出现的证据，不机械重复上一问题。用户要求直接看答案或停止练习时按意图调整，不强制填写提交标记。

## 主动深挖

先回答用户的核心问题，再检查其材料尚未覆盖的机制、假设、边界、失败、代价与替代方案。选择会改变理解或行动的重点，说明为何值得展开；用户没有提到不代表用户不懂。

沿“具体情境—机制或反例—证据—处理选择—验证—适用边界”推进主要问题，而不是列一串术语后让用户自行研究。工程与 Agent 主题按需使用 [深度探究](../references/inquiry.md) 的责任边界与故障情境。

事实、推断、教学假设和未知明确区分。无法取得的关键证据列出下一步，其余独立内容继续解释；没有信息增量时收束，避免无限自问自答。

## 接续记录

短问答在会话完成，需要长期保存时更新现有主题笔记。练习的原题、用户回答与后续讲解分开；切换到主动探究时保留尚未完成的练习，不代填答案或伪造提交。

记录实际解释、回答和仍未解决的内容即可，不使用问题地图 JSON、响应状态机或格式 validator。问题已解释、当场能做与长期保持分别判断。
