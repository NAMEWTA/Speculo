# 主动探究记录

## Scope

写明原问题、目标、材料范围、事实与假设；不把教学情境当成已经发生的故障。

## Discovery

按问题 ID 给出发现、为何容易遗漏、为什么重要，以及父问题/触发证据。只列相关方向，不凑配额。

## Deep Dive

主要分支讲清机制、反例、所需证据、方案与代价；工程问题说明处理责任层。

## Verification

区分验证设计、已取得证据、实际测试记录和仍未验证的结论。写出输入、可观察结果与通过条件。

## Next

记录停止原因、待证据/暂缓项和一个可选后续。不得把当前轮关闭等同于全部问题解决或学习者已掌握。
