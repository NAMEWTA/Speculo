# 环境与部署资产盘点

先读项目已有环境说明、基础设施配置和部署结果，建立服务器→项目、项目→环境两种可读视图。单环境用一张表即可，多环境可更新 `environments/README.md` 或已有总览。

## 展示真实关系

按用户需要列出环境名、目标节点、连接别名、应用与数据位置、期望/实际版本、共享服务和依赖。说明观察时间以及哪些信息仅来自配置，未检查或过期状态保持可见。

服务器接入、系统基线、应用部署和业务健康是不同事实。不能因为记录中存在服务名或工具可执行就显示正常，也不要用“unknown”掩盖已知的探测失败。

只要求查看已有资料时不自动连接或修改环境；用户要求核对当前实际状态时，按本次范围执行必要只读检查，并记录其结果与缺口。需要变更时接续对应 Work，不让看板按钮隐式授予部署权限。

## 按需生成视图

Markdown 或已有运维页面足够就直接更新。用户需要可浏览 HTML、CSV 或其他导出时再生成，保持项目/服务器关系、观察时间和未知信息一致；不要求固定 FLEET 文件、JSON schema 或视图 manifest。

展示只取必要摘要，不读取或输出私钥、env 密文/明文、token、密码和授权原话。链接到既有配置位置即可，避免把敏感文档复制到公开看板。

交付可打开的实际视图、数据来源与观测范围。视图更新失败只说明视图未完成，不因此重新执行部署或更改真实业务状态。
