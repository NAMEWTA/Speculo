# 版本说明与 GitHub Release 正文

CHANGELOG 中已确认的本版本段落是正文来源；保留 Unreleased。项目使用其他权威发布说明时记录来源。自动生成 notes 可作为补充，不冒充实际变更与风险说明。

## 提取与验证

按项目实际标题格式与语言读取精确版本段落，边界到下一同级版本标题；不要用只适配某种标题的 awk 段落猜测。提取后验证非空、版本一致，包含实际变化、迁移/兼容和风险说明。必要内容缺失则停止发布准备，不用兜底成功文案替代。

多语言项目遵守已确定的主语言或合并策略，不擅自丢弃一种语言。生成正文的临时文件仅用于 --notes-file，不成为新的永久知识源。

## 交付

使用 gh release create/edit 的 --notes-file 或仓库既有 action 的 body_path，按原计划设置 draft/prerelease/latest。调用方必须持有对应远程写入授权。生成器和 API 可能追加 compare 链接，读回时核对关键版本内容而非只看正文非空。

## 已发布正文补全

先固定 repo/tag/SHA 与当前正文，比较人工变更。只有明确要求补全的准确版本才更新，记录授权、前后摘要和读回结果。已有 npm 包不重发，tag 不移动。批量修复需要明确版本集合，逐项记账，失败停止后续写入。

## 归属

T 的发布使用原 TRI 回执；其他调用方直接复用时写自己的报告。docs-sync state 与知识仍由 docs-sync/A 原 owner 负责。
