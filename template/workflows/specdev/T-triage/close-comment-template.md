# Evidence 关闭评论模板

publish 调用 `issue-comment-close` 时使用。先套 `<Path>{roots.workflows}/specdev/T-triage/references/public-projection.md</Path>`。

done 票 `--reason completed`：

```markdown
> *This was generated by AI during SpecDev T-triage publish.*

## Completion

**Result:** delivered and verified.

**Public commit / PR:** <url or sha or 无公开 commit/PR>

**Verification:**
- Directed: passed | not-run (<reason>)
- Regression: passed | not-run (<reason>)
- E2E: passed | not-run (<reason>)

**Residual risk:** <可公开残余风险或「无」。>

Marker: `specdev:<change>:T-01:published`
```

纳入的 cancelled 票 `--reason not_planned`：

```markdown
> *This was generated by AI during SpecDev T-triage publish.*

## Cancelled

**Reason:** cancelled-already-implemented | cancelled-out-of-scope

**Notes:** <指到已有公开位置或 ADR / 用户决定；不贴内部路径。>

**Public commit / PR:** <url or sha or 无公开 commit/PR>

Marker: `specdev:<change>:T-01:published`
```

父索引关闭评论 marker 为 `specdev:<change>:publish-index`，正文列出已关闭的子 Issue 编号与计数。
