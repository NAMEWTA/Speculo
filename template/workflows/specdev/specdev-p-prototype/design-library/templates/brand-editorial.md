# 品牌与编辑叙事 / brand-editorial

当任务包含「品牌介绍、作品探索、合作咨询」时使用。目标平台：desktop / web / mobile；密度起点：comfortable。这些是候选推荐条件，不替代当前项目与用户选择。

## 任务骨架

摄影与文字叙事、作品分类、详情、返回焦点和咨询表单；Apple/Figma择一为主表达，不做双主调拼贴。

## 预览与复用

[打开离线原型](../templates/brand-editorial.html)。此 HTML/CSS/JS 为 Speculo 原创的虚构任务 fixture。所有交互只改本页内存，刷新重置，不发送请求、不付款、不创建真实记录。

复制页面时同时复制所有被引用的本地 CSS/JS/图片及 attribution，保持相对路径闭合。原样板的共享 styles/scripts/assets 不能丢失；新增模板共享 [样式](assets/prototypes.css) 和 [交互](assets/prototypes.js)。复用照片同时保留 [原资产署名](../research-snapshot/ui-gallery/assets/ATTRIBUTION.md)。

## 视觉组合

可选参考：[apple](../visual-references/apple.md), [figma](../visual-references/figma.md)。先选一个主布局和一个主视觉方向，再按 [组合协议](../composition.md) 记录辅助参考的具体角色、覆盖范围与拒绝原因。默认不提问颜色细枝末节，先形成可比较 HTML，由用户确认最终方案。

## 不适用

实时监控；密集数据处理。不要为了套模板改变需求、信息架构、交付数量或已确认项目约束。

## 验证场景

用相同任务和数据比较候选；检查 390px/1440px、长中文、200% 缩放、键盘/focus、reduced motion，以及适用的空/加载/失败/权限/恢复状态。检查界面可见的业务反馈，不用按钮绑定存在代替成功路径。样板验证不替代生成 change 原型的验证；生产行为仍须另验。
