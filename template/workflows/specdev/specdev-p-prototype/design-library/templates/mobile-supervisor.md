# 移动监督与审批 / mobile-supervisor

当任务包含「审批、通知、远程监督」时使用。目标平台：mobile / web；密度起点：touch。这些是候选推荐条件，不替代当前项目与用户选择。

## 任务骨架

待处理项、审批上下文、决定与结果；明确触控目标和取消/恢复。

## 预览与复用

[打开离线原型](../research-snapshot/ui-gallery/05-mobile-supervisor.html)。此入口复用原有研究样板，保持原快照、相对结构和所有字节不变；它是可运行起点，不等于当前 change 已验证。

复制样板时按 [组合协议](../composition.md) 的“离线复制与补齐”保留本地资源闭包、相对路径与 attribution。

## 视觉组合

可选参考：[airbnb](../visual-references/airbnb.md)。先选一个主布局和一个主视觉方向，再按 [组合协议](../composition.md) 记录辅助参考的具体角色、覆盖范围与拒绝原因。默认不提问颜色细枝末节，先形成可比较 HTML，由用户确认最终方案。

## 不适用

手机完整复刻IDE。不要为了套模板改变需求、信息架构、交付数量或已确认项目约束。

## 验证场景

按 [组合协议](../composition.md) 的“审美与行为审查”比较候选并验证；样板验证不替代生成 change 原型的验证，生产行为仍须另验。
