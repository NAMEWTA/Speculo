# 模板选择与视觉组合

在项目事实与需求已定位、准备生成候选时读取。功能模板决定任务骨架，视觉 reference 提供可选择的表达机制；用户最新决定与已确认项目 DESIGN 优先。静态设计库不写 runtime，不自动改写生产 UI 或永久知识。

## 推荐顺序

1. 用核心对象、3–5 个高频任务、输入设备、状态复杂度检索 [catalog](catalog.json) 的 tasks/platforms/avoid。已有 UI 优先保留可复用组件与交互；新项目明确记录缺少既有事实。
2. 从命中模板选一个主布局。默认候选数量仍为项目配置的 3、上限 4；事实只支持两个方向时不凑数。12 个模板是能力清单，不是一次运行必须交付 12 个页面。
3. 对每个候选选择一个主视觉 reference，再按需求加入最多两个辅助 reference。主视觉拥有文字、表面、密度和主操作的一致表达；辅助只影响明确区域或维度。用户明确要求更多组合时记录额外来源与冲突裁决，不静默改变数量。
4. 用户给出参考时优先评估其适配；用户没有偏好时，依据任务与代码基线自主推荐并生成 HTML，不等待用户先选颜色。已确认的项目规则直接继承，只有冲突或高影响新取舍需要提前询问。
5. 为每个候选使用相同真实任务、数据、页面和状态。结构、层级或任务入口有实际差异；不把换色当作三个方案。用户看到 HTML 后可选一个、要求调整或指定组合；没有最终确认不能伪造用户接受。

## 组合记录

每个候选记录以下信息，存入 P 拥有的当前 change 工件，不修改此库：

| 字段 | 含义 |
|---|---|
| 主模板 | 一个 catalog template ID，说明任务匹配与不适用条件 |
| 主视觉 | 一个 reference ID，或明确 project-existing/custom 并记录证据 |
| 辅助参考 | reference ID + role（排版/表面/组件/页面区域）+ 明确作用范围 |
| 项目继承 | 基线 locator/revision，复用的 token、组件、导航和状态 |
| 局部覆盖 | 被覆盖规则、理由、仅本 change 或待提升的范围 |
| 裁决 | 冲突、采用方、拒绝方、用户决定或可逆假设 |
| 证据 | 固定上游 revision/hash 与所读原文节；截图推断明确标注 |

只选一个主信息架构和一组语义 token。相同 role 不允许两个未裁决 owner；如两个参考定义主按钮、密度或焦点，明确选择其一。Figma 的营销色块不成为编辑器工具栏；Apple 的产品大片不成为后台默认留白；Notion 的营销页不证明笔记产品交互；暗色原文未覆盖的浅色主题必须由项目独立设计与验证。

## 离线复制与补齐

原始 Markdown 保持原字节，归一化指南单独维护。只复制本次采用样板及其本地资源闭包，保留相对目录、许可和 attribution。复制样板页面时同时复制所有被引用的本地 CSS/JS/图片及 attribution，保持相对路径闭合；原样板的共享 styles/scripts/assets 不能丢失，新增模板共享 [样式](templates/assets/prototypes.css) 和 [交互](templates/assets/prototypes.js)，复用照片同时保留 [原资产署名](research-snapshot/ui-gallery/assets/ATTRIBUTION.md)。字体默认使用项目已有或系统字体；图片优先使用用户资产或本库已归属样例。浏览器可直接打开的 HTML 不应依赖 CDN、远程字体、远程图片、网络 API 或在线 catalog fetch。

每种候选都补齐项目适用的正常、空、加载、失败、权限、取消、重试和恢复路径；文案、时序和信息保留由行为合同决定。上游 Known Gaps 不会取消这些义务。原型只证明模拟路径。

## 审美与行为审查

先审任务是否清楚、主内容是否占据正确层级，再审文字节奏、对齐、密度、表面、图片裁切和细节一致性；检查是否出现通用卡片墙、装饰抢主体、按钮无结果、假数据掩盖真实长度等问题。每项问题落到具体页面、状态与修复，不以“现代”“高级”替代判断。

用相同任务和数据比较候选；运行真实浏览器在 390px 与 1440px 检查，再按项目设备补充；测试键盘/focus、200% 缩放、长中文、reduced motion、适用主题，以及适用的空/加载/失败/权限/恢复状态。检查界面可见的业务反馈，不用按钮绑定存在代替成功路径。样板验证不替代生成 change 原型的验证；生产行为仍须另验。保留来源、观察、修复和截图证据。最终 HTML 确认与永久设计毕业仍使用 P/A 的 owning 合同；模板选择不授予实施、外部写入或知识提升权限。
