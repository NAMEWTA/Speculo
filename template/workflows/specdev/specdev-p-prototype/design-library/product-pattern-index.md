# 按任务选择可运行样例

保留 12 个可以直接打开的 HTML 样例。它们提供可观察结构和局部交互，不是完整业务系统；数据、人物和操作以各页面的示意标记为准。用它们验证思路，再适配项目真实对象。

| 样例 | 适合观察的任务与结构 | 复用时优先检查 |
| --- | --- | --- |
| [高密度 IDE](research-snapshot/ui-gallery/01-dense-ide.html) | 图标轨、上下文导航、多区域编辑 | 面板数量、焦点、快捷键与工作区面积 |
| [单色控制台](research-snapshot/ui-gallery/02-monochrome-console.html) | 技术工作台、状态与紧凑数据 | 层级、状态可辨识度、长内容 |
| [柔和个人 AI](research-snapshot/ui-gallery/03-soft-personal-ai.html) | 对话、个人内容与低压任务入口 | 输入、历史、进行中与失败反馈 |
| [响应式 Web](research-snapshot/ui-gallery/04-responsive-web.html) | 常规 Web 导航与宽窄布局 | 导航折叠、主要行动与滚动 |
| [移动监督](research-snapshot/ui-gallery/05-mobile-supervisor.html) | 窄屏查看、监督与决策 | 充分上下文、触摸、返回与确认 |
| [跨平台工作区](research-snapshot/ui-gallery/06-cross-platform-workspace.html) | 不同设备的任务分配 | 核心对象与状态一致性、平台能力边界 |
| [本地内容](research-snapshot/ui-gallery/07-local-first-content.html) | 文档、内容组织与编辑 | 保存、离线与同步是否真实，文件与内容关系 |
| [媒体优先](research-snapshot/ui-gallery/08-media-first.html) | 图片、封面、媒体浏览 | 画幅、加载、选择、缺失素材与键盘路径 |
| [企业数据](templates/enterprise-data.html) | 请求列表、筛选与处理详情 | 选择、数据密度、实际操作结果与恢复 |
| [营销转化](templates/marketing-conversion.html) | 产品价值、分段叙事与演示入口 | 内容可信度、主要行动、表单和窄屏 |
| [品牌编辑](templates/brand-editorial.html) | 作品与品牌叙事、大图和节奏 | 图片用途、阅读顺序、视觉与内容的比例 |
| [商业服务](templates/commerce-service.html) | 服务详情、信任信息与预约选择 | 可用性、价格含义、模拟预订与真实交易边界 |

[本地画廊](gallery.html) 提供浏览入口。前 8 个来自保留的研究快照，后 4 个是 Speculo 已有的独立示例；两组资源均保留必要 CSS、JavaScript 和本地图片。图标与照片署名见 [素材说明](research-snapshot/ui-gallery/assets/ATTRIBUTION.md)。

选择后只复制当前任务需要的源和资源，保留许可。页面能打开不等于所有交互都适合当前业务；应实际操作，并覆盖本项目重要状态。
