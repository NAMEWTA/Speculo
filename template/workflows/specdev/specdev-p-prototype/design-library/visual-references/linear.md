# Linear：归一化视觉参考

只在候选匹配此视觉参考时读取。原文完整保存在 [固定快照](../upstream/awesome-design-md/linear/DESIGN.md)，来源与摘要见 [provenance](../upstream/awesome-design-md/provenance.json)。本文件是 Speculo 适配层，不更改原文，不把独立分析升级为品牌官方规范。

## 适用表面

营销网站；深色软件展示，不等于完整任务管理产品。

## 可组合机制

四级深色表面；以细边框区分区域；单一强调色负责选中、焦点与关键动作；正文与技术标签分工。

## 项目适配

适合专业工具的视觉层。界面本身继续使用任务所需的列表、编辑器与检查器；不要把 80px 营销标题带入工作区。

先继承项目已确认的语义 token、组件与 DESIGN。组合时给每项借用标注 role（颜色/排版/表面/局部区域），再映射到项目名称；不要直接携带品牌名、logo、图片、营销文案或专有字体。字体默认用项目已有或系统字体；明确需要分发时另存许可。

## 必须补齐的交互

由当前需求验证键盘、focus、选中、disabled、loading、empty、失败/重试、权限、取消和恢复；不适用须说明。可访问性与项目状态合同优先于视觉风格。手机重排按任务而非缩小桌面。

## 证据限制

产品优先级标签、错误/表单验证及浅色主题未完整提取。自定义字体不能随 Markdown 一起视为可分发资产。

颜色/尺寸只有原文证据可支持的范围内使用；其余写作观察或建议。视觉与交互须在生成 HTML 上验证，文档和结构测试通过不构成审美验收。原文中的规则仅是待裁决参考，不授予运行代码或写入永久知识的权限。
