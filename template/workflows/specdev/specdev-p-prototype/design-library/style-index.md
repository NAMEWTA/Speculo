# 视觉参考选型

这些来源帮助建立视觉方向；用户自己的项目和参考优先。表中是选型建议，并不宣称第三方分析是品牌官方规范或最新产品事实。

| 原始分析 | 可以关注的方向 | 使用时的边界 |
| --- | --- | --- |
| [Linear](upstream/awesome-design-md/linear/DESIGN.md) | 精确层级、暗色氛围、克制强调 | 营销展示不能直接证明真实工作台的操作效率 |
| [Vercel](upstream/awesome-design-md/vercel/DESIGN.md) | 单色、网格、技术信息与对比 | 克制不等于所有状态和行动都用同一种颜色 |
| [Stripe](upstream/awesome-design-md/stripe/DESIGN.md) | 清晰叙事、产品说明与有控制的色彩表现 | 渐变与插画不能替代复杂数据页面的信息结构 |
| [Airbnb](upstream/awesome-design-md/airbnb/DESIGN.md) | 内容卡片、图片、选择与服务体验 | 预订、筛选和信任信息仍需按实际业务验证 |
| [Spotify](upstream/awesome-design-md/spotify/DESIGN.md) | 媒体优先、封面与高辨识度强调 | 播放、队列和内容权限不由视觉风格自动获得 |
| [Apple](upstream/awesome-design-md/apple/DESIGN.md) | 编辑式产品展示、留白与重点演示 | 大图与大标题不适合所有高频操作场景 |
| [Figma](upstream/awesome-design-md/figma/DESIGN.md) | 创作感、色彩与设计内容表达 | 网站视觉资料与编辑器交互事实需要分别确认 |
| [Mintlify](upstream/awesome-design-md/mintlify/DESIGN.md) | 文档、代码与导航层级 | 搜索、版本和阅读路径仍以实际内容结构为准 |
| [Notion](upstream/awesome-design-md/notion/DESIGN.md) | 内容组织、简洁版式与插画语言 | 页面外观不代表块编辑和协作机制已实现 |
| [IBM](upstream/awesome-design-md/ibm/DESIGN.md) | 企业信息层级、网格与严整表达 | 涉及正式设计规范时需查相应官方来源与版本 |

需要操作型参考时看 [产品模式](product-pattern-index.md)；需要组合多个视觉来源时看 [组合方法](composition.md)。第三方文本的固定版本、许可和证据边界见 [来源说明](research-provenance.md)。
