# 显式项目内 UI 预览

仅在用户明确要求项目内预览时加载；默认仍是离线持久化 UI 包，候选缺省 3、配置上限 4，用户显式数量覆盖；项目基线与 change DESIGN 的权威不变。

记录项目路由/启动命令、允许的临时文件写集、现有未提交改动和清理方案。用当前项目真实组件与布局环境，加隔离 mock/stub 阻断生产写入；不连接真实付款、发信或数据变更服务。使用 ?variant= 或项目等价参数切换方案，可加底部切换器；快捷键不能劫持输入框、编辑区或浏览器功能。

设计决定写入 change DESIGN，项目相对观察与原型源码回写 design-system.md。验证相同任务、viewport、状态与交互，先形成可操作预览与离线 comparison/final，再集中确认。仍运行物化/设计包校验和指定 `--prototype-id` 的 prototype gate，记录真实浏览器证据。临时预览不是另一权威源。

只清理本次明确拥有且内容未漂移的临时修改，保留原有用户内容；发现 owner/内容冲突时停止该清理并记录剩余写集。清理完成或明确 handoff 后才能把项目预览分支标完成。不自动创建分支、提交、推送或删除 worktree。
