# Logic Prototype

当问题涉及业务逻辑、状态转换或数据形态时使用。

## 形态

构建单个自包含 HTML/CSS/JS 文件，无框架、打包器或服务器，双击即可运行。顶部用领域语言写明唯一问题。

实际逻辑放在独立纯模块中，可使用 reducer、状态机、纯函数集或有清晰方法面的模块；逻辑不得引用 DOM。页面只是调用模块的薄外壳。

## 界面

按顺序呈现：

1. 问题与一行说明；
2. 带字段标签的完整当前状态；
3. 每个动作一个、始终可用的自由按钮；
4. 至少 happy、edge、illegal 三个引导演练，每次从已知初始状态开始。

每次操作后重绘完整相关状态，并说明刚发生的变化。标签使用业务语言，不显示 reducer/内部代码术语。

## 边界

默认内存状态；问题明确涉及持久化时才使用标记为 `PROTOTYPE - DELETE` 的临时本地数据。无测试、生产数据库、抽象层或超出问题的错误处理。答案确认后由 I 正式实现；HTML 外壳只保留在临时分支。
