# UI Prototype

当问题是页面外观、信息层级或交互布局时使用。

## 选择宿主

优先把变体嵌入现有页面，保留真实页头、侧栏、数据获取、参数和认证，只切换渲染子树。确实没有合理宿主时，才按项目约定创建明显标注 prototype 的临时路由。

## 变体

默认 3 个，最多 5 个。每个变体必须在布局、信息层级或主要操作入口上结构不同，不能只换颜色或文案。使用项目现有组件和样式系统，但不要共享会限制结构探索的布局抽象。

## 切换器

使用 `?variant=` 保存并分享选择。浮动底栏提供前一项、当前名称、后一项和循环切换；左右方向键可切换，但 input、textarea 或 contenteditable 聚焦时不截获。切换器必须在 production build 隐藏。

变更操作使用桩；UI 原型不写生产数据。完整相关状态在每个变体中可见。
