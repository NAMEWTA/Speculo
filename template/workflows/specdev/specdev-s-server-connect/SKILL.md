# 服务器接入

使用用户给定的目标或已有环境记录定位同一服务器。核对地址、端口、账号、连接方式和已验证的主机身份；信息冲突时先查清，不从当前目录、上次操作或默认 HOME 猜目标。

优先使用已有 SSH config、agent、凭据管理或项目连接工具。首次信任与认证必须有真实依据，不能自动接受不明主机指纹，也不把密码拼进可见命令或日志。

## 只读核实环境

连接后识别真实主机、登录账号、工作目录、系统、权限以及本次需要的工具与服务。用户已明确部署根时核对它；未明确且有多个真实候选时说明取舍并消歧。

区别连接可用、目录可写、运行环境就绪和项目健康。接入成功不表示所有应用可部署，更不授权改 sshd、账号 HOME、系统服务或其他项目。

缺少必需工具时，优先复用现成方式；确需引导安装则按项目支持的来源与已授权范围处理。保留原连接可用性，避免在验证替代路径前切断当前入口。

## 留下下一次能用的信息

更新对应环境文档：清楚的目标名、连接引用、账号/权限边界、部署根、应用与数据位置、已核实事实和观察时间。秘密值继续留在凭据管理处。

已有记录与实机不同，先说明差异并核实，确认后更新当前事实。更换账号或地址时保留能说明同一目标的依据，防止同名环境悄悄指向另一台机器。

只要求接入时返回实际连接结果与缺口；已要求准备或部署时继续 [主机维护](../specdev-h-host-manage/SKILL.md) 或 [项目部署](../specdev-d-project-deploy/SKILL.md)。
