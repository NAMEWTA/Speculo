# 把判断变成集体行动

用来分析执行为何卡住，以及怎样改善工作方法。方法服务具体目标，不要求建一套组织协议或人为制造政治仪式。

| 方法 | 当代工作中的可用部分 | 检验方式 |
| --- | --- | --- |
| 从一线经验形成办法，再回到实践 | 收集实际问题，综合可复用规律，让受影响的人试用并反馈 | 建议是否解决了真实困难，是否漏掉不善表达的人 |
| 批评与自我批评 | 针对事实、行为与可改进机制复盘，也检查自己的判断 | 改动是否发生，问题是否减少；避免人格评价和公开羞辱 |
| 共同理解与学习 | 解释目标、依据、边界，让成员知道如何自主判断 | 能否在新情况中作出一致且合理的选择；不以口号一致代替理解 |
| 讨论与执行 | 让掌握不同信息的人表达意见，说明谁决定、怎样落实和何时重议 | 决定是否可执行，异议是否有回应，新增证据是否能触发调整 |
| 工作方法与协调 | 将重点、节奏、信息共享和协作规则结合 | 关键问题是否有实际负责人、资源与反馈，不只是在会上被提到 |
| 人才与发展 | 按任务所需能力分工，提供支持与成长机会 | 用实际表现校准判断，不以标签替代能力，也不把支持变成越权控制 |
| 任务与方法一起解决 | 给目标同时提供工具、路径、权限与必要资源 | 执行者是否真的具备完成条件；失败时先查缺失条件 |
| 责任与纪律 | 明确承诺、边界、例外和后果，保持规则可理解、可申诉 | 对同类情况是否一致，是否保留必要自主空间 |

## 《党委会的工作方法》的可借鉴要点

这篇历史文本包含十二条工作方法。应用于现代团队时，可归纳为以下实际动作：

- 协调者不仅分派工作，也研究如何让不同成员有效协作。
- 把需要共同解决的问题公开到相关人员面前，及时互通掌握的信息。
- 不懂的事情向真正了解现场的人请教；听取意见之后仍要分析证据。
- 围绕中心任务协调其他事项，让节奏互相配合，不能只强调一个方向而放任基础工作失效。
- 对重点持续跟进，用数量与实例了解现状；避免“已讨论”等于“已解决”。
- 会前明确要解决的问题与所需材料，会议、文字和流程保持简明。
- 与不同意见者合作，承认贡献、局限和失误，避免由一次错误否定整个人。
- 分清问题性质与主要方面；历史文本中的政治界限不能直接用作现代团队分类工具。

这份归纳不是逐字引用，也不是对历史组织制度的整体移植。具体原文见 [党委会的工作方法](../books/src/147-党委会的工作方法.md)。其他入口见 [篇目导航](../books/README.md)。

## 一个足够具体的行动建议

说明谁需要参与、眼前要完成的结果、完成它所需的条件、如何获得一线反馈，以及什么变化意味着需要改法。已经存在的负责人、工具和例会可以直接复用，不为了方法完整性新增层级或表单。

当用户只需要个人决策时，组织方法可能完全不需要。多人协作涉及他人承诺时，区分建议分工与已经取得的同意。
