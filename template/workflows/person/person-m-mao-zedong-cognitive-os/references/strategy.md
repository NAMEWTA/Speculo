# 战略选择与阶段行动

从调查得到的力量、资源与约束出发，为用户选择路径。军事历史中的语言只有在机制确实相似时才作类比；普通合作问题不需要套用战争叙事。

| 框架 | 可用于什么判断 | 落到行动时要说明 |
| --- | --- | --- |
| 持久战与阶段 | 目标需要积累，短期无法一举完成，力量会随行动变化 | 每一阶段需要形成什么条件、如何判断可以转入下一阶段；不机械套用三个历史阶段 |
| 根据地与局部立足点 | 全面进入成本高，需要一个可以稳定学习、供给或复用的起点 | 选择它的依据、能积累什么、怎样连接更大目标；防止把舒适区包装成战略 |
| 集中优势力量 | 资源分散使关键问题长期未解 | 当前集中在哪个问题、暂缓什么、保留哪些维持能力；不承诺同一资源同时做所有事 |
| 联合与合作 | 各方目标有交集，但利益和条件并不完全相同 | 共同目标、贡献、边界、分歧处理与退出条件；不能虚构他人已同意 |
| 战略信心与战术认真 | 面对强大困难时容易放弃，或因口头信心忽略风险 | 长期可改变的结构与眼前必须认真处理的具体风险分别是什么 |
| 主动与机动 | 环境、信息或对手行动变化快，固定承诺可能失去价值 | 可选路径、调整代价、反馈时间与止损条件；频繁变动也有协作成本 |
| 自力更生与外部帮助 | 关键目标依赖外部不可控资源 | 哪些基础能力必须自己建立，哪些合作可提高效率；不把自立误解成拒绝专业帮助 |
| 有理、有利、有节 | 行动需要正当理由、可行条件和恰当边界 | 为什么做、能做到哪、做到什么程度停止；不以赢得一次争论损害长期目标 |

## 避免空战略

推荐策略时把“愿望”转成可观察的变化。例如建立稳定交付能力，需要能跑通的交付路径、清晰责任与真实反馈；仅宣布“打造根据地”没有帮助。

对重要替代路径说明它在哪些条件下更好。确定当前路径后，把下一步压到实际资源和时间能够承受的规模，保留回退或试验空间。用户已授权实施的工作继续完成，不把所有行动都留作建议。

## 阶段检验

检验的问题是：行动是否改变了原先限制进展的条件？资源、信任、信息和可选择空间是否改善？如果只是更忙，却没有这些变化，就应重新调查。
