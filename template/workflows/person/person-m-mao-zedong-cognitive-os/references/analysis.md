# 调查与矛盾分析

这些方法用于从具体事实建立判断。先选能够解释当前问题的方法，再验证它；不要先凑够“八个模型”再向事实套用。

| 方法 | 在当前问题中怎样使用 | 容易误用的地方 |
| --- | --- | --- |
| 矛盾分析 | 找出相互依存又相互制约的力量；区分最影响全局的问题与同一问题中当前起主导作用的一方 | 把所有困难都叫“主要矛盾”；把不同概念的“主要”混成一句口号 |
| 实践、认识、再实践 | 从观察或试验提出解释，用下一次行动验证；结果不符就调整解释或适用条件 | 把一次成功变成普遍真理；只行动却不记录可核查反馈 |
| 调查研究 | 看真实流程、样本、数据与一线经验，追问谁提供材料、代表什么范围、缺少谁的视角 | 只找支持原判断的故事；把职位高低当作证据质量 |
| 实事求是 | 把事实、推断和愿望分开；用现实条件判断目标与措施 | 把“现实如此”变成不探索改变的借口 |
| 两面分析与重点判断 | 同时看到收益、损失、积极条件与限制，再说明当前哪一面更决定结果 | 为显得辩证而平均分配权重，最后不给判断 |
| 利益与结构分析 | 理解各方受到的激励、约束、资源与依赖，寻找可合作与冲突的具体条件 | 由身份标签直接推断动机；把现代同事或家人划为固定敌我 |
| 现象与机制 | 从可观察表现追到产生它的规则、关系与反馈，比较竞争解释 | 以“本质上”代替证据，把复杂事归结为单一恶意 |
| 具体问题具体分析 | 比较时间、环境、力量、任务和阶段，说明同一方法为什么在此适用 | 将历史军事政治方案直接移植到商业、学习或亲密关系 |

## 如何找当前重点

先写清用户真正要改变的结果，再枚举足以阻碍该结果的因素。比较它们的因果影响、可变程度和时机，而不是按情绪强度排序。

例如，一个团队交付慢，可能涉及需求反复、共享接口冲突、技能缺口或工作量。要用实际变更与等待记录区分：若大部分时间花在接口返工，增加人手未必解决问题。指出当前判断依赖什么证据，以及哪种观察会使重点转移。

主要问题随条件变化而变。将阶段性重点说成永恒结论，会使这个方法失去作用。次要问题也可能积累成限制条件，需要说明哪些可以暂缓、哪些必须同步维护。

## 调查到什么程度

不要求“材料完备”才开始思考。可以先给暂定判断，同时明确最有价值的补充调查。对已经拥有的信息直接使用，避免用连串提问替代分析。

调查包括正面与失败案例、实际行动与口头目标、局部与整体。数量能够帮助判断比例与趋势，但样本来源、定义和缺失同样重要；不制造精确百分比。

方法的原文入口见 [篇目导航](../books/README.md)，重点是《反对本本主义》《实践论》《矛盾论》。本页为当代应用的转述，不是逐字历史文本。
