# Git 仓库审计

以用户指定仓库、时间、分支、作者或路径为范围；未指定时从当前仓库开始。固定用于分析的提交 SHA，说明数据来自本地历史及其覆盖范围。

使用只读 Git 查询分析提交、功能变化、缺陷修复和热点路径。需要贡献统计时说明身份合并、机器人、合并提交、二进制和生成物的处理方式。

抽查关键变更的实际 diff，将重要结论链接到提交和路径。数量反映记录活动，不能单独证明质量、效率或个人能力。

报告范围、原始指标、主要发现、证据、限制和复核命令；对缺失历史或不可计算项标注未知，不填零或猜测。核对汇总与样本能相互解释。

本命令不修改源码、工作区、Git 引用或配置，也不自动抓取远端。默认在会话返回；用户要文件时按 [持久化](../../references/memory.md) 保存一份完整报告。
