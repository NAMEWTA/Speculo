# 查看进度

按用户指定项目或主题定位现有记录。软件交付优先读取 `.agents/speculo/.speculo/releases/` 的相关记录；学习、创作和咨询读取各自主题笔记，不默认加载全部历史。

用实际文件、Git 和已记录的检查或部署回执核对完成情况。显示正在处理的结果、未解决事项、证据位置和可继续的下一步；归档作为历史单独说明。

区分保存的记录与本次观测，时间只用真实来源。未联系远端就不宣称实时健康；资料缺失或相互冲突时标注未知，不当成零进度或擅自接管。

默认只在会话返回，不写文件、不修复状态、不移动归档，也不自动部署。用户需要保存摘要时按 [持久化](../../references/memory.md) 放在已有记录或一份简短笔记中。
