# README 整理

README 帮助新读者判断用途、开始使用并验证结果。结构服从项目实际规模与读者任务，不强制居中 Header、徽章数量、九段式结构、Tech Stack 表或 Footer。

## 内容与事实

按读者需要检查：名称与具体定位、最小 Quick Start、安装前提、常用入口/配置/限制、详细文档与贡献/许可导航。已有清晰内容保留；项目简单时合并章节，API 详表、架构解释和长教程放到独立文档。目录摘要、截图和徽章仅在帮助使用或定位时保留。

| 事实变化 | 核对内容 |
|---|---|
| 包名、定位、公开能力 | 开头、能力说明、限制 |
| CLI/API/配置 | Quick Start、示例、参考入口 |
| runtime、依赖、分发 | 安装、平台/版本要求 |
| 架构、目录、CI、发布或许可 | 相关导航、徽章、贡献与许可证 |

全局整理也检查未出现在 Git diff 的陈旧说明。事实来自当前 manifest、CLI 帮助、schema、代码、测试与 CI。示例给出可复制命令和成功结果，不承诺没有证据的耗时或未来能力。

## 语言镜像

README.md 使用英文（EN），README-ZH.md 是中文镜像；用户明确要求其他语言时按其要求。两份在章节含义、命令、URL、表格与关键约束上对等，顶部互相链接，代码实体不翻译。已授权的同步范围内同时修正两份；缺镜像时将新建纳入目标。镜像未完成时该组不能标为已同步，不阻塞独立文档。

## 验证

核对版本、路径、命令与真实源，检查链接、图片和语言切换；实际运行或静态验证受影响的安装/核心示例。删除无采用或使用价值的重复说明，保留必要边界与许可。无法执行的示例明确未验证，不为文案整理默认运行全部业务测试。
