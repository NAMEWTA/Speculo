# 交接

按用户指定范围核对当前请求、实际修改、交付物和未完成事项。只提取接手者需要知道的事实，不重写整个对话。

优先更新现有交付记录或主题笔记，保留目标、重要决定与来源、当前分支或版本、实际检查结果、阻塞和下一步。多项工作分别链接其原记录，避免复制正文。

用户要求保存且没有合适记录时，按 [持久化](../../references/memory.md) 新建一份简短接续笔记。引用能稳定定位的文件或提交，保留必要的授权范围和未执行动作。

交付实际位置及下一步。交接不把未验证工作标成完成，也不产生新的操作授权。

接续时先回读记录和所指的实际文件、Git 或系统状态，再处理未完成事项；历史描述与现状不符时先查明差异。
