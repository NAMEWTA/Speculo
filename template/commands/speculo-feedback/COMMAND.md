# Speculo 反馈

从用户指定的使用经历、错误或产物中找出具体问题，区分缺陷、文档缺口和改进建议。保留复现条件、实际与预期行为、影响及最小相关证据。

去除重复和无依据的推测，形成简洁的标题、正文与验收条件。涉及日志或环境信息时只保留定位问题所需内容，移除凭据及无关私人信息。

提交目标固定为 `NAMEWTA/Speculo`。先查现有 issues，发现语义重复时链接已有记录；分析或草稿请求到此即可。

用户明确要求提 issue 时，复用覆盖本次内容和目标的授权，提交已整理的提案。不能访问远端时保留可提交正文，说明未创建。

逐项核对真实 issue 链接；请求超时先检查是否已经创建，再决定重试。报告已创建、重复和失败项，不自动评论或关闭其他 issue。

需要保存且没有合适原记录时，按 [持久化](../../references/memory.md) 留一份反馈笔记；真实 issue 已承载完整内容时只保留链接。
