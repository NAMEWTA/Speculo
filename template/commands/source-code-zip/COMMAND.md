# 源码 ZIP

确定源目录、输出位置，以及打包当前工作区还是指定提交。使用环境已有的归档工具；用户已指定材料或过滤规则时按其范围处理。

先列出候选文件，检查源码、必要配置样例、锁文件、构建脚本和所需资源是否齐全。默认排除 Git 内部数据、依赖缓存、构建产物、已有归档和真实凭据；不因扩展名就删掉必要配置。

核对未追踪文件与符号链接，避免遗漏用户要求的内容或把链接外的无关目录带入。输出放在待打包文件集合之外，已有同名文件保留或按用户要求处理。

生成 ZIP 后读取其文件清单并抽查关键文件，确认归档可打开且内容来自约定版本。保留目录结构，不改动源文件。

交付 ZIP 路径、版本或工作区说明、文件数量与主要排除项。缺少依赖或运行材料时说明复建限制；打包失败就报告原因，不把预览清单称作 ZIP。

用户需要长期保留时按 [持久化](../../references/memory.md) 放入指定交付位置；无需额外命令状态或报告。
