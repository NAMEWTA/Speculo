# 上游评估

从 Git 和项目说明确认产品分支、上游仓库及评估范围。已有明确目标直接复用，无法区分多个上游时先消歧。

默认用本地 refs；用户要求最新上游时从已确认 remote 刷新并说明结果。纯只读预览不改变项目文件或 refs，缺少远端数据就说明覆盖限制。

记录产品 tip、观测到的上游 tip、共同基点和可证实的已集成版本。刷新或镜像更新不等于集成；无法从历史证明的检查点标注未知。

比较实际 diff，并将关键变化对应到项目需要保留的定制行为。需要合并模拟时在隔离临时位置进行，保持当前工作区内容和分支不变。

分别说明文本冲突、自动合并后的语义风险、定制冲突和本地未提交修改的重叠。没有文本冲突不能证明功能兼容；未执行的验证保留为缺口。

给出建议集成范围、重要风险、所需验证和固定 SHA 的复核方式。本命令提供评估，不自动合并、提交或推送。

用户需要保存时按 [持久化](../../references/memory.md) 复用现有交付记录。只有实际集成历史和验证结果已经存在，才更新记录中的集成检查点。
