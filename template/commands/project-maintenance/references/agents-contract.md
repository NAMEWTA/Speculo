# AGENTS 与工具入口

AGENTS 保存项目独有事实、任务入口、作用域边界与验收；不能变成 README 教程、目录百科或通用编程规范。默认增量修正内容；缺手册、实际作用域变化或用户要求重建时读 [发现与重建](handbook-discovery.md)。全局盘点覆盖所有自有手册，增量指修订方式，不是只审查 diff 命中文件。

## 内容选择

保留精确任务命令、难以发现的入口、架构/所有权边界、真实回归陷阱和完成标准。可从工具直接可靠获得的冗长枚举改为事实源指针；必要的短命令与安全提醒可以就近保留。与当前实际全局规则重复的通用要求删除或收敛，无法确认宿主默认行为时不凭模型升级推断规则无用。

CLI 管理的 Speculo 区块保持原 owner；其中按任务触发的共享方法入口应保留，不因方法适用范围广而作为通用规范删去。详细规则留在对应合同，不复制到项目手册。

参考 [最小骨架](../assets/agents-template.md)，按项目需要组合：项目事实、任务入口、边界与停止条件、验证与完成。没有事实支撑的章节省略，不固定 13 章或字数。模块手册仅说明相对父级的独有内容，父级负责导航；目录划分本身不要求新手册。

规则按任务触发：先定位目标及直接调用方，再读取当前分支资料；已加载且未变化内容不重读。普通修正不强制通读、备份、全源字符统计或全套测试。授权可复用，阻塞限于受影响分支；必要安全边界、数量、工具和恢复义务保留。

## CLAUDE 适配

有独立 AGENTS 作用域且需要 Claude 适配时，新增或明确由工具拥有的 CLAUDE.md 使用三行导入：

```markdown
# CLAUDE.md

@AGENTS.md
```

已有用户内容默认保留。只有获批迁移时，完整保留其事实与宿主特定约束到 AGENTS/相应适配说明，再改成导入。已覆盖同一迁移的授权不重复询问。其他宿主不被强制创建 CLAUDE；普通 Markdown 链接不等于宿主导入。

## 完成

事实、路径、命令和作用域与项目一致；README、AGENTS、项目 Skill 之间没有重复权威或冲突。各适用任务能定位必要资料、验证和完成标准，不产生无依据门禁。写入效果服从调用方 audit/update/commit，结构检查不认证宿主实际调用。
