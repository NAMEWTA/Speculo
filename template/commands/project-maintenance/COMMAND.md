# 项目维护

按请求选择文档、知识、归档或其组合。用户只要求审计时返回发现；要求修复或整理时在该范围完成，不重新询问已经明确的授权。

对照实际代码、配置和结果查找过时事实、断链与重复说明。保留一处主要维护位置，其他地方改为有用的指针；项目入口只保留发现和工作所需的信息。

需要提纯知识时按 [持久化](../../references/memory.md) 保留长期决定、背景、设计和已验证故障经验，优先更新现有记录，不要求每项工作生成所有分类。

需要归档时先确认工作已经结束或明确终止，保留未解决事项的入口和历史验收版本，再移动记录并检查链接。当前设计与环境说明仍在长期位置维护。

删除前辨明唯一来源、用户材料和仍在使用的内容，保留无关编辑。遇到冲突只停止相关部分，继续独立且已授权的维护。

报告实际修改、验证和未处理项；已有记录足够时不另建报告。提交或推送仅执行当前请求覆盖的范围，按需核对实际 Git 结果。
