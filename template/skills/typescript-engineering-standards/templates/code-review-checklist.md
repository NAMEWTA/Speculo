# TypeScript Code Review Checklist

## 正确性与安全

- [ ] 外部输入已验证。
- [ ] 权限、安全和敏感信息处理正确。
- [ ] 错误路径不会造成数据损坏或状态不一致。

## 类型与 API

- [ ] 没有无说明的 `any`、双重断言或 `@ts-ignore`。
- [ ] 公共 API 输入、输出和错误契约明确。
- [ ] 互斥状态使用可靠模型，分支穷尽。
- [ ] 空值和可选语义清晰。

## 异步与资源

- [ ] Promise 已等待、返回或显式处理。
- [ ] 超时、取消和重试策略合理。
- [ ] 监听器、Timer、连接和进程已清理。
- [ ] 无明显竞态或过期响应覆盖问题。

## 架构与维护

- [ ] 文件位于正确领域和运行环境。
- [ ] 文件名具体，职责单一。
- [ ] 依赖方向正确，无循环依赖。
- [ ] 没有无意义共享抽象和 Barrel。
- [ ] 文件、函数和状态复杂度合理。

## 测试与交付

- [ ] 新行为有适当测试。
- [ ] 缺陷修复有回归测试。
- [ ] 测试确定、可诊断且不过度 Mock。
- [ ] 格式、Lint、类型检查、测试和构建通过。
- [ ] 无无关格式化、重命名或生成文件变化。
