# Node.js、CLI 与跨平台规范

仅在项目实际包含 Node.js、CLI、Electron 主进程或服务端代码时生成相关部分。

## 路径和文件系统

- 使用 `node:path` 等标准 API，不手工拼接平台路径。
- 考虑 Windows 分隔符、盘符、UNC、符号链接、路径遍历和大小写差异。
- 文件操作明确编码、原子性、权限和清理路径。

## CLI

- 参数解析、验证、命令执行和错误渲染分离。
- 错误写入 `stderr`，机器可读正常输出写入 `stdout`。
- 明确定义退出码。
- 底层领域逻辑不直接调用 `process.exit()`。
- 信号处理和资源清理集中管理。

## 环境变量

在启动边界一次性读取、验证和标准化环境变量，转换为只读配置对象。业务代码不得在各处直接访问 `process.env`。

## 子进程和 Shell

- 优先使用参数数组而非拼接 Shell 字符串。
- 明确超时、取消、信号、输出上限和清理。
- 用户输入不得未经转义进入命令。

## 多运行环境

Node、浏览器、Electron 主进程、预加载和 Worker 使用独立类型与构建配置。只复制实际存在的运行环境结构，不机械创建不相关目录。
