# 安全、性能与国际化

## 安全

- 外部输入在边界验证。
- 路径防止目录穿越。
- SQL 和命令使用参数化接口。
- HTML 输出转义，谨慎处理原始 HTML。
- URL、重定向、文件类型和消息来源校验。
- 不将 Token、密码、Cookie、私钥和完整个人信息写入日志。
- 不把秘密放入浏览器 Bundle。
- 权限判断集中管理，前端隐藏按钮不能替代服务端鉴权。

## 性能

- 不做没有测量依据的微优化。
- 优先减少算法复杂度、I/O 次数和大型对象复制。
- 大列表、日志和文件采用分页、流式、窗口化或虚拟化。
- 缓存定义键、容量、淘汰、失效和一致性策略。
- Timer、监听器和缓存都有上限与清理。
- 非直观性能优化使用简短 WHY 注释并配回归或基准测试。

## 国际化

仅在项目有多语言需求时生成：

- 用户可见文本不散落为硬编码字符串。
- 文案键按领域命名。
- 插值使用命名参数。
- 不用字符串拼接构造自然语言句子。
- 日期、数字、货币和复数使用国际化 API。
- 错误日志与用户提示分离。
