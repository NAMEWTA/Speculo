# TypeScript 代码评审检查清单

## 架构和命名

- [ ] 文件位于正确运行环境和领域。
- [ ] 领域内部保持局部平铺，没有无意义单文件目录。
- [ ] 文件名具体，没有万能 `utils`、`helpers`、`common`。
- [ ] 依赖方向正确，没有新增循环依赖。

## 类型和实现

- [ ] 外部输入已验证，未传播 `any`。
- [ ] 公共函数和契约类型明确。
- [ ] Promise、错误、取消和资源清理完整。
- [ ] 注释解释 WHY，而非复述代码。
- [ ] 文件和函数未无理由超过项目预算。

## 测试和交付

- [ ] 单元测试与实现共置。
- [ ] 缺陷修复包含回归测试。
- [ ] 格式、Lint、类型、测试和构建门禁通过。
- [ ] 未通过关闭规则或跳过测试绕过失败。
