# 维护项目资料

AI 入口：`command/project-maintenance` · [权威方法](../../template/commands/project-maintenance/COMMAND.md) · [命令目录](README.md)

核对当前文档、提纯知识并整理已结束记录。

## 请求例子

> 整理本项目的开发文档和重复知识，修正过时内容，把已经完成的 v0.5 归档。

## 会得到什么

对明确范围完成修订和回读，保留唯一来源、用户材料与历史设计版本；不同事项的冲突分别处理。

## 接续与范围

纯审计只返回发现；要求修复时实际修改。提交或推送按请求范围执行，不为整理资料创建业务游标。

只有需要保存或接续时才更新现有记录；位置与提纯方式见 [流程与持久化](../workflow.md)。
