# 打包源码或工程

AI 入口：`command/source-code-zip` · [权威方法](../../template/commands/source-code-zip/COMMAND.md) · [命令目录](README.md)

按阅读或复建用途生成范围明确的 ZIP。

## 请求例子

> 把这个目录打成方便代码审阅的源码 ZIP，并说明哪些内容没有包含。

## 会得到什么

内置无依赖 Node 工具提供源码白名单、预览和默认敏感项排除；默认不含 YAML、锁文件和普通 JSON，不能称为完整工程。

## 接续与范围

若要可复建工程，请明确说明，AI 会保留必需配置、锁文件和资源并检查秘密。参数见命令旁的技术参考。

只有需要保存或接续时才更新现有记录；位置与提纯方式见 [流程与持久化](../workflow.md)。
