# 反馈 Speculo 问题

AI 入口：`command/speculo-feedback` · [权威方法](../../template/commands/speculo-feedback/COMMAND.md) · [命令目录](README.md)

把真实失败提炼为可复现、可验收的提案。

## 请求例子

> 将这次原型验收被跳过的问题整理清楚，查重后向 Speculo 提 issue。

## 会得到什么

保留原目标、实际错误、版本、必要证据、影响和验证条件，查重并按请求创建后读回真实链接。

## 接续与范围

只要求分析时交草稿；不自动评论或关闭其他 issue。远端结果不确定时先查是否已创建，避免重复。

只有需要保存或接续时才更新现有记录；位置与提纯方式见 [流程与持久化](../workflow.md)。
