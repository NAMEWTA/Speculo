# 评估上游变化

AI 入口：`command/upstream-assess` · [权威方法](../../template/commands/upstream-assess/COMMAND.md) · [命令目录](README.md)

比较 fork 与一个明确上游版本，保护本项目定制。

## 请求例子

> 评估上游最新版本对我们的插件改造有什么影响，指出冲突和必须保留的行为，先不要合并。

## 会得到什么

固定产品、上游与基点 SHA，说明文本冲突、语义风险、定制重叠和验证重点。观测 tip 与已集成版本分别记录。

## 接续与范围

要求最新时可刷新已确认 remote；纯只读预览不改 refs。评估完成不自动推进集成检查点或合并分支。

只有需要保存或接续时才更新现有记录；位置与提纯方式见 [流程与持久化](../workflow.md)。
