# 交接与接续

AI 入口：`command/handoff` · [权威方法](../../template/commands/handoff/COMMAND.md) · [命令目录](README.md)

把接手者真正需要的上下文更新到现有记录。

## 请求例子

> 给下一会话留下 v0.6 的交接，保留当前分支、设计版本和没有完成的工作。

## 会得到什么

通常得到原记录的一次更新，包含目标、关键决定、结果、阻塞与下一步。已有 PR/部署对象保留真实链接，避免接续时重复操作。

## 接续与范围

下一会话先核对实际代码与系统，再继续剩余工作。无需固定 TASK/REPORT 或整段聊天转存。

只有需要保存或接续时才更新现有记录；位置与提纯方式见 [流程与持久化](../workflow.md)。
