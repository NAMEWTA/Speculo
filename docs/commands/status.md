# 查看进度

AI 入口：`command/status` · [权威方法](../../template/commands/status/COMMAND.md) · [命令目录](README.md)

看当前成果、阻塞和下一步，不自动执行后续工作。

## 请求例子

> 请用 status 看 v0.6 到哪一步，区分代码验证和我要求的最终验收。

## 会得到什么

返回当前记录与产物依据、可靠的时间和可继续入口。缺失资料标为未知；保存的环境观测不等于实时健康。

## 接续与范围

如果需要继续实现，直接指明交付和目标；若安装本身异常，使用 CLI doctor，而不是修改业务记录。

只有需要保存或接续时才更新现有记录；位置与提纯方式见 [流程与持久化](../workflow.md)。
