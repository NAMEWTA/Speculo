# Person：调查、实践与钢人化论证

Person 保留两套不同的方法，入口见 [Person SKILL](../../template/workflows/person/SKILL.md)。选择取决于问题性质和用户意图，不能把它们压缩成通用的“多角度分析”。

## 毛泽东认知方法

`person/mao-zedong-cognitive-os` 以调查研究、实践与认识、矛盾及主次关系、阶段条件等概念分析具体问题。重点是把抽象判断落回事实、利益关系、资源条件和可以验证的行动。

使用时先判断真实问题与当前材料：哪些事实来自调查，哪些只是推断；哪些因素决定当前局面，哪些条件变化会让原判断失效；行动怎样取得新的证据。方法为分析提供视角，不替代专业事实或可执行的现实约束。

Work 保留原文资料库和专门的方法参考。需要引用时先检索相关篇目，再读原文核对；逐字引用、转述、现代应用分别说明。历史文本保留其语境，不冒充历史人物对今天的问题发表意见，也不把未经核对的流行句子当原文。

适合的请求：

> 用这套调查与矛盾分析方法，分析我们团队交付慢的原因。先区分已有证据和需要补查的信息，再提出可验证的改进。

## 钢人化论证

`person/steelman-deliberation` 重建各方最有力且对方能够认可的论证，分清事实争议、价值取舍、假设和不确定性，再比较证据与后果。

钢人化不要求把弱证据与强证据视为同等可靠，也不要求每个议题都凑成对称两边。某种立场缺乏支持时应说明。最终建议要落到用户的目标、可逆性、代价和会改变结论的新信息。

适合的请求：

> 团队对自建还是采购有分歧。分别重建双方最强论证，指出真正需要验证的假设，再按我们的约束给出建议。

## 输出与持久化

通常直接给出分析、关键依据与可采取的下一步。需要长期推进时，将问题、真实事实、重要取舍、待验证假设和后续结果更新到项目已有记录。

两种方法可在有意义时互相补充，但不要求每次都运行两遍，也不要求固定轮次、闭合状态或专用表单。分析框架的结论始终允许根据新证据修正。
