# 系统时区与区域：字段级修改

## 输入与输出契约

明确目标城市/时区 ID、要改的字段、用户或系统作用域。只改时区就不顺带改语言、键盘、NTP、浏览器或账号国家；不从 IP 推断这些偏好。

逐字段报告原值→新值、实际读回、待登录/重启、未改项与本轮回滚位置。权限不足或修改后发生用户并发改动时停止，不覆盖其他设置。

示例：“把 Windows 当前用户时区设为纽约，只改时区。”应进入本技能；“Claude Code 在美国节点上提示地区错误，请修 DNS 泄漏。”不应由本技能接管。

先确认实际目标主机、系统、版本、当前用户和作用域（当前用户/系统/登录窗口/浏览器）。只读请求不建备份、不改配置。用户只要时区时，不改语言、键盘、NTP、浏览器、账号国家或位置服务。

按需读 [macOS](references/macos.md)、[Windows](references/windows.md)、[Linux](references/linux.md)。脚本在 WSL/远程环境运行不能代表宿主 Mac/Windows。缺少命令或权限时停在可读项，不直接写底层文件绕过拒绝。

## 选择目标与前置验证

用户指定城市/时区优先。只有明确要求按代理出口对齐，才允许使用现有代理路径查询地理数据；说明第三方将看到出口 IP。单个 echo 请求不代表所有应用出口，多出口/城市不确定就不猜。公开 IP 地理信息不应被用来推断键盘、语言或账号所在地。

使用该系统接受的时区列表验证 ID；Windows ID 与 IANA ID 不可互换。语言包、locale 与用户输入法分别核对，目标语言前置但保留已有对象、输入法和顺序。具体语言/键盘仍有歧义时不扩大修改范围。

## 快照、修改与恢复

POSIX 可用 `mktemp -d` 并限制目录权限；Windows 使用当前用户私有目录下的新 GUID 子目录，检查 ACL，不假定 chmod 有效。每轮不覆盖旧快照，保存本轮会改的字段/文件原内容、权限/所有者、哈希和“原先不存在”。快照可能含敏感偏好，只保存在本地私有目录。

先预览字段差异，沿用已有具名授权；无变化不写入。仅为固定用户指定时区、且已授权时处理自动时区，不顺带关闭定位或自动对时。语言、系统 locale、纸张、度量、登录窗口和浏览器各自是不同作用域。

不更换 NTP、不手设时钟、不关闭 TLS 或防火墙。时间服务器解析到 fake-ip 范围时停止该源的探测，不据此断言全局同步失败。浏览器运行中不写偏好；仅在用户明确要求且确认 Profile 后修改应用语言。

写后逐项读回。回滚前检测本轮后用户改动；只恢复本轮字段与原先不存在状态，冲突停止，不整文件覆盖后续配置。语言重登录、系统 locale 可能重启的生效条件按系统报告，不自动退出会话或重启。

## 交付

列出目标时区、修改作用域、原值/新值、读回证据、待登录/待重启、未做项及本地回滚位置。改变时区或语言不会修复源 IP 路由，不对服务地区资格作承诺。
