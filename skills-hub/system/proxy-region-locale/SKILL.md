# 系统时区与区域

先确定实际主机、系统版本、目标地点、要改字段和作用域。时区、显示语言、键盘、区域格式、账号国家与网络出口分别处理，不能从一个设置自动推导其他偏好。

## 选择目标

用户指定的城市或时区优先。只有明确要求按代理出口对齐时，才通过现有代理路径查询位置；多个出口或定位不确定时说明差异，不以单次 IP 地理结果替用户选择语言。

系统接受的时区 ID 必须核对：Windows ID 与 IANA ID 不可直接互换，夏令时也不等于固定 UTC 偏移。区域设置不会改变 IP 路由，不能把它当作地区服务报错的网络修复。

## 做字段级修改

只改时区就不顺带修改语言、输入法、NTP、位置服务或浏览器。需要语言变更时，保留既有输入法和用户排序偏好；目标语言包是否存在与设置是否写入分开检查。

区分当前用户、系统、登录窗口和浏览器 Profile。WSL 或远端执行成功不能代替宿主验证，不能将另一系统的路径与命令直接套入。

修改前保存本轮原值，预览有实质影响的差异，并在已有授权范围内执行。无变化无需写入；只读请求也不创建配置备份。权限拒绝不能通过直接写底层数据库或注册表绕过。

固定时区所需的自动时区调整按目标处理，不自动关闭全部定位或对时服务。系统时间、NTP、网站账号国家和日历事件都不因区域请求而改变。

## 生效、回滚与交付

逐字段读回，确认目标作用域和实际值。有些语言或系统 locale 需要重登录或重启，按真实系统要求说明，不自动结束用户会话。

回滚只恢复本轮字段；出现后续用户编辑时先处理冲突，不整份覆盖其他偏好。

交付原值与新值、修改范围、实际观察、待生效步骤和恢复位置。无法访问实际桌面或浏览器时明确该部分尚未验证。
