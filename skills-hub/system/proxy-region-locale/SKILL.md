# 时区与区域设置

确定实际目标主机、城市/时区、字段和作用域，沿用用户已有选择。时区、语言、键盘、账号国家和网络出口是不同设置，不相互推断。
只改时区时不顺带修改语言、NTP、位置服务或浏览器。用户明确要求按代理出口对齐时，才通过现有代理查询位置；不确定地点就询问，不凭单次出口猜语言偏好。

按系统读取 [macOS](references/macos.md)、[Windows](references/windows.md) 或 [Linux](references/linux.md)。验证系统接受的时区 ID，Windows ID 与 IANA ID 不能直接互换。
目标语言放到所需位置并保留已有输入法。确认目标是用户、系统、登录窗口还是特定浏览器；WSL/远端执行结果不能代替宿主验证。

修改前保存相关原值，预览差异并在已授权范围内执行。只读请求不写配置。权限拒绝不通过直接改底层文件绕过。
逐字段读回，说明是否需要重登录或重启；不自动结束用户会话。回滚只恢复本轮字段，发生后续编辑时先处理冲突。

交付实际变更和生效状态。区域设置不会改变 IP 路由，也不能保证解决服务的地区限制。
