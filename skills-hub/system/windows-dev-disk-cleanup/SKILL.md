# Windows 磁盘清理

确认原生 Windows、目标卷和授权范围。只读盘点不删除、不卸载、不停止进程；已有具体授权直接沿用，新增删除对象需让用户决定。
按 [Windows 命令与数据边界](references/windows-cleanup-workflow.md) 扫描相关目录并建立卷空间基线，不跟随 junction/reparse point 或触发云占位文件下载。

用一份简短清单记录准确路径/产品 ID、用途、占用、决定和实际结果；目录大小是估计值，不代表能释放多少物理空间。
优先官方卸载器和缓存清理方法。使用 `LiteralPath`，拒绝空路径、卷根和越界链接，不能用通配删除代替对象判断。

保留源码、用户数据、凭据、活动工具链、数据库与容器卷。替换运行时前先验证替代版本，再在不依赖旧版本的会话中移除它。
WinSxS/ResetBase、还原点、WinRE、pagefile、更新数据、WSL/Docker 虚拟盘是独立效果，不属于普通缓存清理。不要直接处理活动 VHDX 或强制解锁在用文件。

按批准范围分批执行，发现身份变化、锁定或未知共享依赖就保留并说明。不自动重启；有清单不等于删除可以回滚。
测量卷真实可用空间变化，并检查保留工具和相关项目，交付已完成、失败、保留及待重启项。
