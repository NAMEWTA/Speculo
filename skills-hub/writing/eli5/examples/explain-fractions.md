# 为什么1/2加1/3不能把分母直接相加？

这是教学风格演示，不是对本用户能力的诊断，不是完整35分钟课程，也不是用户已经作答的记录。

**因为“半块”和“三分之一块”的块大小不同，要先换成同样大的小块，才能把块数相加。**

把同样大小的一整块蛋糕切成6等份。原来的半块就是其中3小份，原来的三分之一块就是其中2小份。合起来有5小份，所以是5/6块。

```text
同样大的一整块，分成6份： [ ][ ][ ][ ][ ][ ]
1/2块对应3份：            [■][■][■][ ][ ][ ]
1/3块对应2份：            [■][■][ ][ ][ ][ ]
合计：3份 + 2份 = 5份，每份都是整块的1/6
```

文字等价物：每一小份都占相同整体的六分之一；半块等于三小份，三分之一块等于两小份，共五小份。图的两行分别表示两份数量的换算，不是把同一位置重复涂色后计算覆盖面积。

正式一点：**通分（finding a common denominator）**，就是把分数换成相同分母而不改变数值。1/2=(1×3)/(2×3)=3/6；1/3=(1×2)/(3×2)=2/6，因此1/2+1/3=(3+2)/6=5/6。

分母说明“一整份被分成多少等份”，分子说明“取几份”。直接写成(1+1)/(2+3)=2/5，改变了每一份的大小，没有保留原来的数量。

还有一个容易漏掉的条件：这里两次说的“一块蛋糕”大小相同。半个大蛋糕和三分之一个小蛋糕，不能不交代大小就合成“某个统一蛋糕的5/6”。分数本身的数值相加仍是5/6，但换算实际重量时必须明确相同单位和参照整体。

蛋糕只是帮助理解的模型，不是数学证明；它尤其不适合直接表现负分数。这里的算式推导展示了数值关系。换成相同容量的一升量杯，道理不变：先统一每份代表的容量，再合并份数。

**记住：先让“每份多大”一致，再数一共有几份。**
