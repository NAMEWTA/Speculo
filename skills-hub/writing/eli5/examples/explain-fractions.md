# 为什么 1/2 加 1/3 不能把分母直接相加？

这是教学示例，不是用户的答题记录。

“半块”和“三分之一块”的块大小不同，要先换成同样大的小块，才能把块数相加。

把同样大小的一整块蛋糕切成 6 等份。原来的半块就是其中 3 小份，原来的三分之一块就是其中 2 小份，合起来有 5 小份。

| 原来的数量 | 换成六分之一大小的小份 |
|---|---|
| 1/2 块 | 3 份 |
| 1/3 块 | 2 份 |
| 合计 | 5 份，也就是 5/6 块 |

正式地说，通分就是把分数换成相同分母而不改变数值：1/2 = 3/6，1/3 = 2/6，所以 1/2 + 1/3 = (3 + 2)/6 = 5/6。
分母说明一整块分成多少等份，分子说明取几份。直接写成 (1 + 1)/(2 + 3) = 2/5，改变了每份大小，没有保留原数量。

这里两次说的一块蛋糕必须一样大。半个大蛋糕和三分之一个小蛋糕，不能不交代大小就合成某个蛋糕的 5/6；实际重量需要使用相同单位与参照。
蛋糕模型有助于直觉，但不适合直接表现负分数。上面的等值分数推导说明数值关系，换成相同容量的量杯也能使用同一方法。
