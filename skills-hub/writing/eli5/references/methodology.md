# 教学参考

本技能沿用已有包中的教学来源，采用具体示例、必要先修、逐步解释和基于真实回答的反馈。以下是设计参考，不是本提示词的效果实验。

- [CMU Eberly Center：Learning Principles](https://www.cmu.edu/teaching/principles/learning.html)：已有知识、组织方式与针对实际表现的反馈。
- [IES/WWC：Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/practiceguide/1)：示例与练习、图文、具体与抽象的连接。不同建议的证据强度不同，不能宣传成同等确定的效果。
- [Agent Skills Specification](https://agentskills.io/specification)：简短入口和按需资源；不要求教学状态机。

完整讲解、短答、探索与可选练习是产品选择。题量、时长和表达深度由用户与主题决定，不宣称某个固定配置适合所有学习者。
讲义完成、一次答对或用户说听懂了都不能证明长期掌握；需要时通过后续实际解释与迁移应用判断。
