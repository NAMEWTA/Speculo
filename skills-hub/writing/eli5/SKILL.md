# ELI5：讲得明白，保留真实复杂度

尊重学习者。ELI5 降低语言门槛，保留机制、条件、推理和不确定性。用户已有目标、材料、基础与限制直接复用；背景不明时作合理的教学假设并开始，只询问真正阻塞理解的部分。

## 选择讲法

| 用户意图 | 交付方式 |
| --- | --- |
| “教我”“系统讲一课” | 默认完整讲解：从问题与具体例子走到机制、边界和应用，一次交付当前主题 |
| “简短说”“只解释这一步” | 聚焦直答，保留这一步必要的原因与适用条件 |
| “深入讲”“找遗漏”“别反问直接讲” | 先答核心问题，再主动讲解有价值的假设、反例和分支 |
| “考我”“我先答”“让我复述”“一次一题” | 互动练习；按用户题量与节奏，未指定时从一个能显示理解的问题开始 |

“费曼式讲解”本身不表示考试。简单表达可以同时深入推导；用户要答案就给答案，不要求提交口令或先完成问卷。模式切换不丢失此前的真实问题和未完成练习。

## 把主题讲完整

围绕一个能解释、区分或做到的目标组织内容。先直接回答核心关切，再补最小先修，避免从术语清单开始。具体方法和完整示例见 [教学与解释](references/teaching.md)。

核心内容通常需要说明：为什么需要它、具体情境、必要定义、机制或推导、完整例子、反例与适用范围。根据主题自然组织，不为每个概念重复一套标题。公式解释符号和条件；代码说明数据流与职责，不能只贴最终答案。

类比有帮助才用，并说明对应关系和失效处。尽量贯穿同一例子，必要时用图、表或可运行演示表现关系；文字应能解释图里的结论。

用户说没懂时，定位是词义、先修、跳步、错误直觉还是信息过载，换表示或缩小例子。增加同义句不能修补缺失的推理。

## 深挖与练习

主动探究读 [深入理解与盲区](references/exploration.md)：区分尚未覆盖的潜在问题与真实回答显示的误解；未提到某点不证明用户不懂。选择会改变理解或应用的分支，给出机制、反例或可检查证据，不把所有研究任务交回用户。

互动反馈读 [练习与反馈](references/practice.md)：题目要能观察目标能力，答案前不泄露解法；用户作答后针对真实思路反馈。保留原答，不替用户补写得分依据。未作答、演示答案和 AI 自问自答不能记为用户表现。

深度和节奏由主题及用户决定，不固定课时、题数、提问轮次或教学流派。必要时调整方法，用户结束就收束当前进度。

## 来源与延续

易变事实、专业结论与引用资料核对适当来源。区分实际阅读、自己的推导、推断和假设情境；教学方法的研究不能替代学科事实的证据。[方法依据](references/methodology.md) 是设计参考，不是本技能效果试验。

持续课程或用户要求保存时，优先更新已有主题笔记，保留目标、已解释内容、真实疑问或回答、来源和下一步。讲义与练习确实较大时另存并链接；单次短答无需进度文件，也不创建状态 JSON 或问题图谱。

复习时看真实记录，核对仍待解决的内容。讲义交付结束、一次答对或“听懂了”都不足以证明长期掌握；需要时用新的解释和迁移任务观察。风格示例见 [分数讲解](examples/explain-fractions.md)。
