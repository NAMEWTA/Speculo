# 拆 JD

`brief.md` 冻结原文。拆成三列：

- 硬门槛：年限、学历、语言、工作许可、必须到岗的城市
- 核心：反复出现的职责和技能
- 加分：出现一次的工具或行业

只有岗位名、没有 JD 时，可以检索公开招聘页补一份，并在 brief 顶部写「非官方原文」和 URL。检索不到就停，让用户粘贴，不要用通用岗位描述冒充这家公司的 JD。

匹配表用四格，不要只用一个百分比：

| 格 | 含义 |
|---|---|
| 已覆盖 | 语料里有直接证据 |
| 翻译后覆盖 | 真事换了岗位用词，claim 仍在 |
| 诚实缺口 | JD 有、库无 |
| 不写入 | 真实但和本岗无关，或用户标记不公开 |
