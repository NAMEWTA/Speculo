# 把匹配缺口变成可执行提升

从真实岗位要求和经历证据出发，区分三类问题：

| 问题 | 合适行动 |
| --- | --- |
| 已经做过，但表达不清 | 调整项目选择、责任说明和成果顺序 |
| 可能做过，但证据不够 | 查找项目记录、核对统计口径、补充公开产物或请用户确认 |
| 尚无能力或实践 | 安排学习与实际产出，完成后再更新经历 |

先处理会改变本次投递判断的项目。短期可以修正表达、找回证据；较长时间用可展示的小项目、实验或实践补齐能力。周期依据用户时间与目标，不强制 7/30/60/90 天模板。

每项行动说明要解决什么缺口、完成后能拿出什么证据、怎样检查结果。计划可以是普通清单，规模小无需另建文件。

未完成的练习、证书或项目保持未来计划身份。不要建议伪造证书、修改任职时间、把团队成果写成独立完成。后续有真实产出再更新经历原件并考虑新的投递表达。
