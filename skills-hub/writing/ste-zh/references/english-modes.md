# 英文实用写法与严格核验

默认采用实用技术英语：清楚的对象、主动语态、具体动词、稳定术语和容易执行的步骤。用户要求 strict 时再按指定版本的 ASD-STE100 规则与词典核验。

## 实用改写

先保留技术意思，再缩短表达。例如将 “prior to starting the service” 改成 “before you start the service”，通常更直接；项目定义的 API 名和技术名词保持原样。

一步一个主要动作，依赖条件放在动作前。避免含糊的 “it”“this” 和长名词串；需要时写出主语与对象。被动句若能更清楚表达已知范围，可以保留，不为了形式补造执行者。

短句是帮助理解的手段。必要定义和适用条件不能仅为缩短句子而删去。

## 严格模式

官方标准包含写作规则与受控词典。用户提供版本、规则或词典时，分别核对句子结构、词义、技术名词和适用例外；结果说明覆盖范围。

步骤句 20 词、描述句 25 词可以作为常见公开原则的核对线索，不能代替完整规则、例外和官方计词方法。自行列出的近义替换表也不是核准词典。

缺少官方材料时交付可读性改写与明确的未核验项，不标注“STE compliant”或百分比合规。沿用 “en-80” 名称时，它仅表示本技能的实用模式，不是测量出的 80% 合规率。

官方资料入口：[ASD-STE100](https://www.asd-ste100.org/)。改编与许可见 [NOTICE](../NOTICE.md)。
