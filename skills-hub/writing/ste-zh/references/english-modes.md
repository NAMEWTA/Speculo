# 英文模式

转述 ASD-STE100 Issue 9（2025-01-15）公开原则。不是标准原文，不含约 900 个核准词。原文向 ASD 申请：https://www.asd-ste100.org/

Part 1 有 53 条写作规则，分 9 节。规则条数相对 Issue 8 未变。technical name 改称 technical noun。

共同规则：一名一义；步骤句不超过 20 词；描述句不超过 25 词；一句一个指令；主动语态；步骤用祈使句；条件在前；不用完成时和短语动词；多词名词不超过 3 个词。

en-strict 用于步骤、警告、错误信息和工具说明。优先短词：utilize/leverage → use，commence/begin → start，facilitate → help，prior to → before。这不是核准词表。

en-80 是英文默认模式，用于 README 和说明文。保持句长和主动，不锁定词表。仍删除 delve、seamless、robust、leverage。

不得写 STE compliant。可以写：按本技能规则改写，未对照官方词典。
