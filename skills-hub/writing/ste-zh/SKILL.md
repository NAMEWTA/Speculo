# 简化技术中文 / STE 写作

本技能规定两件事：Agent 向用户汇报时怎么写，以及用户要求改写技术文本时怎么写。依据是 ASD-STE100 的公开原则，不是标准原文。

ASD-STE100 只规定英文。中文规则是这些原则的改写，编号是本技能自定的。权利、改编范围和非官方声明见 [NOTICE.md](NOTICE.md)。

## 何时启用，何时停止

用户说出下列任一意图时启用：`/ste`、「用 STE 规范输出」、「按 ASD-STE100 汇报」、「简化技术中文」、「简化技术英语」、STE100 rewrite、disambiguate、80% STE。

启用后，本会话里写给用户的文字按本技能写，直到用户说「停止 ste」或 `stop ste`。与其他输出风格冲突时，本技能优先。项目规定了输出语言时，用规定的语言，写法仍按本技能。

不要因为普通问答、营销文案、故事或代码审查而自行启用。不要把本技能套到代码、代码注释、commit message，或 Agent 写入项目的文件上。用户明确要求改写某一份文档时，只改那一份。

启用后的第一条回复用一句话说明后续按本技能写。不要列出全部规则，除非用户要求。

## 模式

先选模式，再写。

| 模式 | 何时用 | 先读 |
|---|---|---|
| zh-report | 中文汇报、进度、排查、请用户决定。默认中文模式。 | [中文规则](references/zh-rules.md) 与 [术语](references/terminology.md) 第 2–5 节 |
| en-strict | 英文步骤、警告、错误信息、工具说明；用户要求 strict、100% 或航空式写法。 | [英文模式](references/english-modes.md) |
| en-80 | 英文说明文、README、评审意见。英文默认模式。 | [英文模式](references/english-modes.md) |

意义优先于用词。没有核准替代词时，改句子结构、保留项目技术名词，或标「未确认」。不得换成近义词后改变事实。

## 中文汇报

第一句写结论。工作状态只用这 10 个词：已完成、部分完成、未开始、进行中、已验证、未验证、失败、跳过、阻塞、未确认。情态词只用「必须」「不得」「可以」。

每个结论写明是否验证，以及验证方法。没有执行的检查不得写成通过。来源没有的事实列入「待确认」，不得用「可能」「大概」「应该是」掩盖。

按回复类型选模板。没有内容的节删除。示例见 [examples/zh-report.md](examples/zh-report.md)。

### 进度说明

```markdown
正在<动作><对象>。
```

### 结果汇报

```markdown
<状态词：做了什么>。

**改动**
- <一条改动一行，写 `路径`>。

**验证**
- 已验证：<检查> — <结果>。
- 未验证：<检查> — <原因>。

**未做**
- <没有做的事> — <原因>。

**待确认**
- <一句一条>。
```

### 排查结论

```markdown
<原因是什么，或原因未确认>。

**现象**：<用户看到的行为>。
**原因**：<一句>。
**证据**：
- `路径:行号` — <这一行说明了什么>。
**建议**：<一个动作>。
```

### 请求决定

```markdown
<由用户决定的事>。

1. <动作>（推荐）— <后果>。
2. <动作> — <后果>。
```

### 多项总结

```markdown
## 术语
- **<词>**：<一句定义>。

## 共同条件
- <所有项都适用的事实，一句一条>。

## <组号>. <组名>
**<原标题>**
- 问题：<现状>。
- 要做：
  - <一个可检查结果一行，条件在前>。

## 待确认
- <一句一条>。
```

原标题保留原文语言。日志、错误信息和命令输出引用时一字不改。

## 英文改写

步骤句不超过 20 个词。描述句不超过 25 个词。一句一个指令。主动语态，步骤用祈使句。条件写在动作前面。不用短语动词，不用堆叠情态，不用完成时。名词串不超过 3 个词。同一个事物只用一个名称。

en-80 保持句长、主动和一句一事，不锁定固定词表。en-strict 还要避免常见非核准近义轮换，见 [english-modes.md](references/english-modes.md)。项目已定义的技术名词保持原样。

## 发出前检查

- 第一句是结论。
- 状态词只来自上面 10 个词。需要状态时，每个结论都有验证状态。
- 没有过程叙述。每个事实能指到来源。
- 一句一事。条件在动作前面。
- 中文步骤句不超过 30 字，描述句不超过 40 字。计数：一个汉字计 1；一个英文单词、数字或代码标识符计 1；标点不计。
- 英文步骤句不超过 20 词，描述句不超过 25 词。
- 没有用「等」或「之类」结束的列举。
- 没有把未执行的检查写成通过，也没有写成官方合规。
