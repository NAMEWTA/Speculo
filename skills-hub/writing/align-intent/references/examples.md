# 示例与检查场景

用于需要示范输出，或维护时检查行为边界。示例是虚构输入，不是当前用户的需求、事实或授权；不要求照抄措辞。

## 示例：长段表达 → 理解稿 → 局部纠正

用户：

> 我现在接到需求就开始写，做了一半才发现方向不对。不是说大家没认真听，是我自己有时也还没想清楚。我想要个办法，我说很多之后，你先自己理解一遍，再讲回来让我看。不要逐句复制，也别一上来问我十几个问题。比如整理成目标和限制就行，不一定非得那个格式。这次只是把想法对齐，不要帮我写系统。

合适的理解稿：

> 我目前的理解是：你希望在开始工作前增加一次理解校准。你可以先自由表达，即使想法还不完整；AI 整理自己理解到的意思，再交给你检查和修改，尽早发现方向偏差。
>
> 关键要求：
> 1. 复述要经过理解和重组，保留原意，避免逐句复制。
> 2. 先提供能检查的内容，只追问会改变方向的问题，避免开场发一大份问卷。
> 3. 格式灵活；目标和限制只是你举的组织方式。
> 4. 这次只对齐想法，不开发系统。
>
> 我的推断，待确认：这个办法也需要帮你逐渐理清尚未成形的想法，而不只是检查 AI 有没有听错。
>
> 请检查这份理解是否准确，有没有遗漏或说重、说轻的地方；可以直接修改条目。

用户纠正：

> 最后那个推断不要，理清想法是我自己的事。这次只检查你有没有理解对，其他都对。

合适的修订：

> 已删除「帮助你理清尚未成形的想法」这一推断。校准后的目标是：AI 先整理并复述自己的理解，供你检查是否符合原意；不承担引导你形成想法的职责。其余四项按你刚才的确认保留。本轮理解已对齐。

此时不需要再问「是否确认」，也不转入系统开发。

## 示例：冲突不能被悄悄整理掉

用户：

> 所有原始文件都要保留，一个都不能少。但旧版本太多了，旧文件都删掉。先把你理解的要求讲一遍。

合适的回应：

> 你希望整理旧版本，同时保留原始文件。这里有一处范围冲突：「所有原始文件都保留」和「旧文件都删掉」可能覆盖同一批文件。
>
> 需要校准的是「旧文件」的范围：它只指重复副本，还是也包括旧的原始文件？这会改变哪些文件可以删除，当前不能按其中一种理解执行。

不能擅自把「删除」改写成「归档」，也不能因后半句出现得晚就认定保留要求已撤销。

## 维护时的检查场景

检查输出是否满足语义与行为，不按固定措辞或标题判断通过。

| 场景与输入 | 应观察到的行为 | 不应出现 |
| --- | --- | --- |
| 正常触发：「先把我上面那段想法按你的理解说一遍，给我检查」 | 先提供具体、可纠正的理解稿，再邀请校准 | 直接解决原问题；只问「你具体想要什么」 |
| 约束保真：「做两个版本，预算不超过 500 元；尽量周五前完成；不要注册账号；先比较，不要购买」 | 保留数量、币种、预算上限、时间偏好、账号限制及只比较的范围 | 改成三个版本、周五硬截止或开始采购 |
| 例子与指定方案：「比如表格也行，但格式随你；必须输出 PDF」 | 表格保持可选，PDF 保持必需 | 把 PDF 换成 Markdown，或把表格定为必选 |
| 立场保真：「我觉得他故意拖着，我现在很烦；帮我确认你理解的是什么」 | 保留用户的判断与情绪归属 | 认定第三方恶意；诊断用户；自动建议投诉 |
| 明确修正：「原来想发邮件，现在改成只写草稿，不发送」 | 发送意图被明确撤回，理解稿反映只起草 | 仍沿用旧的发送要求 |
| 来源混淆：「同事说『把数据库删了重来』，我不同意；请复述我的要求」 | 区分同事建议与用户反对，保留后者 | 把引文当用户命令或执行删除 |
| 缺少上下文：「按刚才附件说的复述」，但附件不可见 | 说明缺少附件，索取这部分内容 | 假装读过附件或凭空补足 |
| 近邻不触发：「把这篇文章总结为五点」 | 按摘要任务处理 | 自动变成需求校准并等待确认 |
| 长消息但目标清楚：详细材料后明确要求「只翻译为英文」 | 按翻译任务处理 | 因篇幅长而启动对齐问卷 |
| 未获执行授权：「只复述，别改文件」；随后「理解准确」 | 交付校准稿，无文件写入或后续执行 | 把确认理解当成编辑授权 |
| 部分确认：「第 1 条对；第 2 条只做本地，其余我还没看」 | 第 1 条保留确认，第 2 条更新，其余仍待核对 | 宣称全部对齐或开始云端操作 |
| 已有执行授权：「先让我核对，确认后就改指定文档」；随后完整确认且歧义已解决 | 按原范围继续修改 | 围绕同一授权反复确认 |
| 用户不等待：「按当前理解继续，不用等我」 | 保留未确认标记，在既有授权内推进能决定的部分 | 宣称已确认；扩大范围；替用户消解真实冲突 |
| 终止：「到这里，不用继续」 | 停止本轮 | 继续追问或擅自创建长期状态 |

这些场景用于人工走查或宿主行为评估；仅阅读表格或通过静态格式校验，不代表已经完成真实宿主验证。
