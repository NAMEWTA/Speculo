# 照片编辑

先看可读原图，区分底图、人物/宠物身份参考与风格参考。素材齐备时使用宿主实际支持参考图的编辑工具；缺图才请用户补充。仅要求提示词时交付提示词，不把它说成成片。

默认自然修饰，保留辨识度、姿态、构图与纹理；用户明确要求创意变化时按指定范围调整。宠物身份取决于毛色、花纹和体态，不能套用人像美颜。
用可辨识的位置说明编辑区、动作、强度和保留项，避免同时要求全局变化与精确像素不变。

按需要取用以下提示示例，不要求全部读取或固定输出数量：

| 目标 | 参考 |
|---|---|
| 去杂物、调光、人像 | [基础修饰](references/basic-retouch.md) |
| 旅行公仔、贴纸、明信片 | [旅行创意](references/travel-creative.md) |
| 美食、涂鸦、手绘 | [社交图片](references/social-effects.md) |
| 证件照、职业头像 | [正式头像](references/formal-portrait.md) |
| 商品换色、电商图片 | [商品](references/product-photo.md) |
| 老照片、摄影与建筑 | [修复和调色](references/repair-and-look.md) |
| 物体、服装、文字、扩图 | [物体与画幅](references/object-and-canvas.md) |

保留原件，对照结果检查身份、数量、文字、边缘和光影；有明显漂移就从原图或合格版本调整。
尺寸、格式与像素保持只按实际结果报告，正式证件要求按具体用途核验。遵守宿主的图片展示方式，不额外上传未要求分享的原件。
