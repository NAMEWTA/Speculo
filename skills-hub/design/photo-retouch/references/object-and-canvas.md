# 物体、服装、文字与画幅

一次只改用户点名的物体、衣服、表面、文字或画布外缘。去掉水印、署名或他人包装上的品牌不写成消除杂物；这种要求不在本文件的模板里完成。

纯色背景的人物或商品分别使用证件照和商品主图，不在这里假装导出透明通道。

## 添加物体

输入：新物体的外观、大小和位置。画面里已有紧密接触的手或桌面时写明接触关系。

```text
在{{位置}}添加{{物体、大小与材质}}。新物体的透视、清晰度和光向与周围一致，并带上应有的接触阴影、遮挡和反射。
不移动原有人物、商品和结构，不改身份、标签与构图。新物体不挡住脸或商品上的关键文字，除非用户要求它位于前方。
```

检查：手指或支撑面没有融在一起；影子方向与场景光源一致；没有多出第二个同类物体。

## 替换一个物体

输入：原物体的位置或名称，以及替代物。同类物体不止一个时必须写清是哪一个。

```text
只把{{原物体及位置}}替换为{{替代物的外观、颜色和大小}}。替代物占据原位置，透视和遮挡与原物体协调，阴影按场景光线重做。
其他物体、人物、背景、文字和画幅保持原样。
```

检查：被替换的物体没有残留边缘；旁边相似的物体还在。

## 服装换色

输入：哪一件衣服；目标颜色。换色不改变版型和材质。

```text
只把{{人物及服装位置}}的颜色改为{{目标颜色}}。
保留面料、缝线、高光、褶皱和剪裁，以及脸、发型、身体、手、姿态、其他衣物和背景。颜色变化停在这件衣服的边缘。
```

检查：肤色、头发和邻近衣物没有被染到。

## 换装

输入：要换上的服装。如果同时换色和换款，先换装，确认身份和手没有漂移后再处理颜色。不同时改服装、姿势和背景。

```text
只把{{人物}}的{{原服装}}换成{{新服装的款式、颜色和材质}}。新衣服跟随原来的身体体积和姿态；只改变这件衣服直接覆盖或露出的区域。
保留五官、年龄、肤色、发型、身体比例、手、姿态、其他未点名的衣物和背景。
```

检查：手和脖子仍然连接自然；身体没有变瘦或变高；脸没有换成更理想化的五官。

## 材质替换

输入：哪一块表面；目标材质。形状保持不变。

```text
只把{{表面及位置}}的材质改为{{目标材质}}。保留这块表面的形状、边缘、透视和原有光向，让新纹理跟随原来的起伏。
周围物体、文字和构图不变，不把整张照片改成渲染图。
```

检查：材质没有铺到相邻表面；直边和厚度还在。

## 替换画面里的文字

输入：能看清的原文字，以及用户给出的新文字。这不是用单词搭物体，也不是在空白处加手写注释。用户没有给出新句子时，不改包装、招牌或海报上的品牌文字。

```text
只把{{表面及位置}}上的「{{原文字}}」替换为「{{新文字}}」。
保留原来的字体风格、颜色、大小、排列和透视，文字贴合该表面的起伏与光影。其他图形、人物、商品和背景不变。
```

检查：新文字逐字正确；没有改到旁边的另一行；弯曲表面上的字仍跟随表面。

## 扩图

输入：目标比例或需要延伸的边；新区域是延续原场景，还是只留出不含新主体的空白。未说明时按原场景延续，不借机重排构图。

```text
保持原照片里已有的人物、物体、建筑和构图留在原来的画面范围内，只向{{哪一条边或目标比例}}延伸。
新区域{{延续相邻的地面、天空、墙面和光线，或只留出与边缘相连的空白}}，衔接处没有硬边。不把主体移到新的位置，不在新区域添加人物、文字或另一个兴趣点。
```

检查：原主体的大小和位置没有因为改比例而被重画；新边缘的纹理和透视接得上。延伸不能恢复镜头外真实存在过的内容。
