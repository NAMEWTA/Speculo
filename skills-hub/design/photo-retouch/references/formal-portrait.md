# 证件照、职业头像与人物换背景

把已有人物照片改成正式头像，或只更换人物身后的环境。默认只处理背景、裁切、光线和用户点名的服装。面部修饰沿用基础修图的轻度规则，只有用户明确要求时才加入；这里不自动磨皮、美白、大眼或瘦脸。

## 纯色证件照

输入：人物底图；底色为白、蓝或红之一。未指定底色时先问，不自行挑选。表情、角度和服装未说明时，保留原表情与服装，采用正脸、头部到胸口的裁切。合照必须指定唯一人物。

```text
以人物照片为身份基准，制作一张{{白色、蓝色或红色}}底证件照。
保留原有五官、脸型、年龄感、肤色、发型、发际线、不对称特征和未要求更换的服装。表情采用{{用户指定表情或原表情}}，头部朝向为{{正脸，或用户指定的轻微侧角}}。
{{仅在用户要求时写入：换成哪一件服装，领口和肩线自然，不改变身体比例与手部}}
背景换为均匀的{{底色}}，没有纹理、渐变和投影。裁切为头部至胸口，人物居中，头顶与肩部留出空隙。
使用柔和的正面光线，减弱眼下和鼻侧的生硬阴影，同时保留皮肤纹理。头发边缘干净，没有白边或抠图痕迹。
不添加文字、证件号码、单位名称、新饰品或其他人物。
```

检查：底色是指定的一种纯色；痣和原有不对称还在；没有把脸修成另一套五官。

## 职业头像

输入：人物底图；背景为浅灰无缝棚或虚化办公环境，由用户指定。未指定时用浅灰棚，不猜测具体办公室。

```text
以人物照片为身份基准，制作一张胸像职业头像。
保留五官、脸型、年龄感、肤色、发型、表情、未要求更换的服装和身体比例。背景改为{{浅灰无缝背景，或用户指定的虚化办公环境}}，其中没有可读文字和无关人物。
光线柔和，面部亮度均匀，保留自然肤质和原有的少量明暗。头发、眼镜与背景衔接自然，没有光晕。
{{仅在用户要求时写入的服装变更}}
不添加姓名、职位或标志。除用户明确要求外，不改变身体朝向。
```

检查：背景没有压过面部；虚化办公室里没有假招牌或乱码；镜框和发丝没有被吃掉。

## 风格只改光色

没有指定风格时用标准均匀光，不要同时叠多种风格。风格只替换光线和色彩句，不改脸。

| 风格 | 写入模板的可见特征 |
|---|---|
| 标准均匀光 | 正面柔光，中性色彩，自然肤色，低对比 |
| 韩式低饱和清新 | 略暖而低饱和，明暗过渡柔和；仍保留脸型、年龄和皮肤纹理，不美白 |
| 美式灰调 | 浅灰背景，中性略冷，对比克制，表情保持松弛，不抹掉原有阴影结构 |

用户另外要求轻度美颜时，只加入基础修图里对应的修饰句，并继续保留痣、雀斑和不对称。

## 人物换到指定环境

输入：人物底图；用户描述的新环境，或一张只提供环境与光线的参考图。参考图里的人不提供身份。未说明新环境时先问，不用证件照纯色底代替。

```text
以人物照片为身份和姿态基准，只把背景换成{{新环境}}。{{若有环境参考：环境的地点、光线和时间以该参考为准，不借用其中的人物。}}
保留五官、年龄、肤色、发型、表情、身体比例、姿态，以及{{未要求更换的服装}}。人物在画面中的大小和机位与原照一致。
新环境的光向、色温与人物受光一致，脚下或接触处有合理阴影。头发和衣物边缘自然，没有白边。景深与原照协调。
不新增人物、文字或与该环境无关的地标。
```

检查：人物没有被重新摆姿势或换脸；阴影方向和背景光一致；指定服装以外的衣物没有被改掉。
