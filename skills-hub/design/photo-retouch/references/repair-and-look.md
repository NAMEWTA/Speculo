# 修复、摄影调色与空间照片

这些任务仍然输出照片。修复只处理可见损坏；调色和换天改变的是光线或天空，不是画种。用户要水彩、公仔、贴纸或拼贴时，改读旅行创意，不用这里的调色句。

## 损伤修复

输入：老照片或破损照片；可见的划痕、灰尘、折痕、撕裂或褪色。用户没有要求上色时不要上色，也不要把画面改成更现代的摄影风格。

```text
修复这张照片上{{具体损坏及位置}}。按周围仍可见的纹理、五官、衣物和背景补上破损处，去掉对应的脏点、折痕和撕裂边缘。
保留原有脸、年龄、服装形制、姿势、背景物体、文字和构图。不新增原图中不存在的配饰、景物或现代物品。
严重缺失的部分只做与周围连续的保守填补，不补出无法从原图辨认的细节。
```

检查：人物是否变成更年轻或另一张脸；衣服款式是否被换成现代服装。大面积缺失不能称为恢复了原貌。

## 按年代上色

只有用户要求上色时使用，并且与修复分开写。不使用「高清修复并上色」这一句代替下面的限制。修复已经去掉的脏点和折痕不要在上色提示词里要求保留；未修复的年代颗粒可以保留。

```text
在已经保持原内容的照片上做克制上色。肤色和服装颜色符合画面所处年代的常见观感，饱和度低，不把黑白照片改成新拍摄的彩色照片。
不改变五官、服装形制、背景和构图，不新增原图没有的图案。
```

检查：没有高饱和的现代妆面或面料。看不清的徽章和文字保持原来的形状，不猜成新图案；没有颜色依据时接近中性，不编造徽记。

## 摄影调色

输入：底图；下表中的一种观感。未指定时不自动套风格。一次只用一种，不与「所有颜色都不变」同时要求。自然曝光和白平衡问题仍用基础修图的调光，不把风格表当作校正。

| 观感 | 可见特征 |
|---|---|
| 黄金时段 | 低角度暖阳光，高光偏金，阴影仍有层次，不只是整图加橙 |
| 夜景 | 天空和暗部转为夜间；光源来自画面里合理的窗、路灯或霓虹；肤色不被统一涂蓝 |
| 季节 | 只改变{{季节}}应有的植被、地面和相应光线；未要求时不更换人物服装 |
| 换天空 | 只替换天空为{{指定天空}}；地平线、建筑和人物轮廓不动；水面和玻璃上的天空反光轻度匹配 |
| 直闪 | 正面硬闪光，阴影短而清楚，肤色不过曝，背景略暗，保留轻微照片颗粒 |
| 户外高饱和 | 日光下天空和植物更鲜明，轻微颗粒，肤色仍自然 |
| 低反差柔光 | 高光柔和，暗部可辨，颜色较淡，皮肤和材质纹理还在 |
| 青橙电影 | 高光偏暖、阴影偏青，对比适中，面部不是一块橙色，画面仍是照片 |

```text
以原照片为内容基准，只把观感调整为{{上表中的一种特征}}。
保持摄影质感，以及人物身份、姿态、服装、建筑几何、物体位置和构图。只允许所选观感写明的光色、天空或植被变化。
不把照片改成插画、水彩、三维渲染或海报，不新增人物和文字。
```

换天空或改季节若会明显改变前景反光，只匹配受影响的反光，不把整张前景重新上色。夜景和黄金时段不保证还原当时的真实曝光。

## 室内与建筑

输入：房间或建筑照片；用户列出的表面、软装或天空。只说「更好看」而没有列出改动时先问，不自行翻新整间房。

```text
以这张{{室内或建筑}}照片的机位为基准，只修改{{用户列出的墙面、地面、家具、天空或其他表面}}。
保持相机位置、开窗、门、墙线和透视，未点名的家具与结构留在原处。新表面的尺度、接缝和光向与原场景一致，直线不弯曲。
不增加未要求的灯具、装饰和人物，不改变建筑的层数与开间关系。
```

检查：窗框和垂直线没有歪；没有把未点名的沙发、桌面或招牌一起换掉。若新天空或新墙色会改变全场光线，只按用户点名的范围匹配，不要求前景每种颜色都与原图相同。
