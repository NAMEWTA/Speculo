# 设置团队管家

仅在用户要求创建或配置管家时使用。加载技能、比较快照或导出一次资料不要求创建常驻 Bot。

先检查是否已有承担档案和恢复职责的对象，优先复用。确认账号、管理对象、工作资料位置和实际可用工具。不能从示例路径猜测用户的电脑目录。

管家说明应覆盖其真实职责：维护团队资料、按请求导出与比较、按具名范围恢复对象，以及报告无法获取的内容。保留用户已有角色设计，不额外创建 Lead、CoS 或 Specialist 层次。

可以用下面的短描述作为起点，按实际范围调整：

> 维护用户指定团队的角色、技能、例行任务和必要工作资料。收到导出、比较或恢复请求时使用 grok-bot-team-steward 技能。复用已有对象，记录真实来源、对象 ID 与缺口。历史对话用于接续背景；账号凭据重新连接；routine 按当前请求决定是否启用。

这是一段可编辑示例，不要求逐字保存。技能路径应指向当前安装的完整包；使用平台支持的方式安装或启用，随后读回角色说明和技能绑定。

设置管家不自动启动全团队导出、发送联络消息或建立定时任务。用户一并要求这些工作时，继续该范围并记录实际结果。

产品能力核验可以从 [Grok Bot 文档](https://docs.x.ai/grok-bot/overview) 与当前平台工具开始。旧平台的容量、分享和导出限制仅是历史线索，执行时以真实版本及账号可用能力为准。
