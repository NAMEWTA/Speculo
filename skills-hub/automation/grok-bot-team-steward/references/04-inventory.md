# 盘点清单

路径约定：执行或转发示例前，将 `/workspace` 替换为本轮已确认工作区、技能路径替换为实际 SKILL.md 所在目录。未完成替换就不发送命令；不得新建根目录来迎合模板。
导出开始时按表勾。勾不上的写 Unknown，不删行。
